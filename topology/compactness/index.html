    拓扑

    紧致性¶

    在分析中,"闭区间上的连续函数必有最大值"这类结论依赖于区间的有限性。紧致性把这种有限性抽象为拓扑性质:空间的每个开覆盖都能抽出有限子覆盖。紧致性是继连通性之后最重要的拓扑不变量,也是从"局部的开集"走向"全局结论"的关键桥梁。

    定义:用开覆盖捕捉有限性¶

    定义 1(开覆盖) 设 \(X\) 是拓扑空间,\(\mathcal{U}\) 是一族开集。若 \(\bigcup_{U \in \mathcal{U}} U = X\),则称 \(\mathcal{U}\) 是 \(X\) 的一个开覆盖。

    定义 2(紧致空间) 若 \(X\) 的每个开覆盖 \(\mathcal{U}\) 都存在有限子覆盖——即存在有限个 \(U_1, \dots, U_n \in \mathcal{U}\) 使得 \(X = U_1 \cup \cdots \cup U_n\)——则称 \(X\) 紧致。子集 \(A \subset X\) 称为紧致集,若 \(A\) 在子空间拓扑下紧致。

    紧致不是"小"而是"有限可控"

    紧致空间可以很大(如闭区间、球面),但它的任何开覆盖都蕴含有限信息。紧致性是"拓扑层面的有限性",与度量空间中的有界性是两个不同概念:有界集未必紧致(如 \((0, 1)\) 的开覆盖 \(\{(1/n, 1)\}\) 无有限子覆盖)。

    例 1 有限空间紧致;有限并、有限积中紧致性表现良好;\(\mathbb{R}\) 不紧致——开覆盖 \(\{(-n, n) : n \in \mathbb{N}\}\) 没有有限子覆盖;离散空间紧致当且仅当有限。

    定理 1(有限交集性质刻画) \(X\) 紧致,当且仅当 \(X\) 的每一族具有有限交集性质(任意有限个成员交非空)的闭集族 \(\{F_\alpha\}\),其全体之交集 \(\bigcap F_\alpha\) 非空。

    证明思想:对开覆盖 \(\{U_\alpha\}\) 取补集 \(F_\alpha = X \setminus U_\alpha\)。开覆盖无有限子覆盖 ⟺ 补集族无有限个成员覆盖 ⟺ \(\{F_\alpha\}\) 的有限子族交集非空(有限交集性质)而 \(\bigcap F_\alpha = \varnothing\)。因此紧致 ⟺ 任何具有限交集性质的闭集族整体交集非空。∎

    有限交集性质是紧致性的"闭集版本",在测度论与泛函分析中常用:例如嵌套闭区间 \(\bigcap [a_n, b_n] \ne \varnothing\) 正是 \(\mathbb{R}\) 紧致性的体现——闭区间套定理(Cantor 交集定理)即有限交集性质在一维的经典形态。

    Heine–Borel:闭区间紧致¶

    定理 2(Heine–Borel) 闭区间 \([a, b] \subset \mathbb{R}\) 紧致。

    证明思想:设 \(\mathcal{U}\) 是 \([a, b]\) 的任一开覆盖。令 \(S = \{x \in [a, b] : [a, x] \text{ 能被 } \mathcal{U} \text{ 有限覆盖}\}\)。\(a \in S\),故 \(S \ne \varnothing\)。令 \(c = \sup S\),则 \(a \le c \le b\)。取 \(U_0 \in \mathcal{U}\) 含 \(c\),因 \(U_0\) 开,存在 \(\varepsilon > 0\) 使得 \((c - \varepsilon, c + \varepsilon) \subset U_0\)。由 \(c - \varepsilon/2\) 的覆盖性,把覆盖 \([a, c - \varepsilon/2]\) 的有限族加上 \(U_0\) 即有限覆盖 \([a, c + \varepsilon/2]\),故 \(c + \varepsilon/2 \in S\),与 \(c\) 是上确界矛盾,除非 \(c = b\)。于是 \([a, b]\) 被有限覆盖。∎

    证明的关键思想:上确界原理。有限性从"推进"中来:每一步只能向前推进一个小开集,而若推进不到 \(b\),就与上确界矛盾。这正是 \(\mathbb{R}\) 完备性的又一次体现(参见 连通性 定理 4 的证明)。

    推论 1(Heine–Borel 定理,一般形式) \(\mathbb{R}^n\) 中的子集紧致,当且仅当它有界且闭。

    证明思想:有界闭集 \(A \subset \mathbb{R}^n\) 含于某闭方体 \([-M, M]^n\);闭方体是闭区间的有限乘积,由有限个紧致集的乘积紧致(定理 6)且闭集含于紧致空间仍紧致(定理 4),得 \(A\) 紧致。反向:紧致集在 Hausdorff 空间 \(\mathbb{R}^n\) 中闭(定理 5),并由"开球覆盖"取有限子覆盖得紧致集有界。∎

    例 2 \([0, 1]\) 紧致,而 \((0, 1)\)、\([0, +\infty)\)、\(\mathbb{Q} \cap [0, 1]\) 均不紧致。闭球 \(\overline{B}(x, r)\) 与球面 \(S^{n-1}\) 紧致。

    推论 2(Bolzano–Weierstrass) \(\mathbb{R}^n\) 中每个有界序列都有收敛子列。

    证明:有界序列含于紧致闭方体,闭方体紧致;在度量空间中紧致等价于序列紧致(定理 8),故存在收敛子列。∎

    紧致性的保持¶

    定理 3(连续像紧致) 设 \(f : X \to Y\) 连续。若 \(X\) 紧致,则 \(f(X)\) 紧致。

    证明:设 \(\{V_\alpha\}\) 是 \(f(X)\) 的开覆盖。则 \(\{f^{-1}(V_\alpha)\}\) 是 \(X\) 的开覆盖,取有限子覆盖 \(f^{-1}(V_{\alpha_1}), \dots, f^{-1}(V_{\alpha_k})\),则 \(f(X) \subset V_{\alpha_1} \cup \cdots \cup V_{\alpha_k}\)。∎

    紧致性因此是拓扑不变量,而且这个定理极其有力:

    推论 3(极值定理) 设 \(X\) 紧致,\(f : X \to \mathbb{R}\) 连续。则 \(f\) 有最大值与最小值。

    证明:由定理 3,\(f(X) \subset \mathbb{R}\) 紧致,由 Heine–Borel(推论 1)它有界闭,故 \(\sup f(X) \in f(X)\)、\(\inf f(X) \in f(X)\)。∎

    这就是"连续函数在闭区间上取到最值"的拓扑解释:最值的存在只依赖紧致性,不依赖任何度量细节。由推论 3 还能立刻得到 Brouwer 不动点定理在一维情形的经典结论:\(f : [0, 1] \to [0, 1]\) 连续必有不动点(考察 \(g(x) = f(x) - x\) 在端点处的符号并用介值定理)。

    推论 4(商空间紧致) 若 \(X\) 紧致,则其任何商空间 \(X/{\sim}\)(见 拓扑空间 的商拓扑)紧致:商映射 \(q : X \to X/{\sim}\) 连续,由定理 3 即得。紧致性在连续像、闭子空间、有限乘积下保持,却不被子空间继承——\((0, 1)\) 是紧致空间 \([0, 1]\) 的非紧致子空间。

    例 3(紧致集间的距离可达) 设 \(K, L \subset \mathbb{R}^n\) 紧致。则存在 \(p \in K\)、\(q \in L\) 使 \(|p - q| = d(K, L) = \inf\{|x - y| : x \in K, y \in L\}\):距离函数 \(d(x, y)\) 在紧致乘积 \(K \times L\) 上连续,由推论 3 取到最小值。这是"两个闭集的最小距离未必可达,紧致即可达"的典型情形(\(K = \{(x, 0)\}\)、\(L = \{(x, e^x)\}\) 两个闭集的距离为 \(0\) 却不可达)。

    定理 4(紧空间中的闭集) 设 \(X\) 紧致,\(A \subset X\) 闭。则 \(A\) 紧致。

    证明:设 \(\{U_\alpha\}\) 是 \(A\) 的开覆盖(开于 \(A\)),写成 \(U_\alpha = V_\alpha \cap A\)。则 \(\{V_\alpha\} \cup \{X \setminus A\}\) 是 \(X\) 的开覆盖,取有限子覆盖;其中至多含 \(X \setminus A\) 一次,去掉它即得 \(A\) 的有限子覆盖。∎

    定理 5(紧集在 Hausdorff 空间中闭) 设 \(X\) Hausdorff,\(K \subset X\) 紧致。则 \(K\) 是闭集。

    证明:证明 \(X \setminus K\) 开。对 \(x \notin K\),由 Hausdorff 性,对每个 \(y \in K\) 存在不交开集 \(U_y \ni x\)、\(V_y \ni y\)。\(\{V_y \cap K\}\) 是 \(K\) 的开覆盖,取有限子覆盖 \(V_{y_1}, \dots, V_{y_n}\),则 \(W = U_{y_1} \cap \cdots \cap U_{y_n}\) 是含 \(x\) 的开集且与 \(K\) 不交。故 \(X \setminus K\) 开。∎

    证明的关键思想:用紧致性把"对每个 \(y\) 找一个分离邻域"的无限任务压缩成有限个,再用有限交得到含 \(x\) 的整块开邻域。这是"有限子覆盖"最典型的用法。

    Hausdorff 条件不可少

    在一般拓扑空间中紧集未必闭。例如带余有限拓扑的无穷集 \(\mathbb{N}\):任何子集 \(A\) 都紧致——取覆盖中任一非空开集 \(U_0\),其补集有限,故 \(A \setminus U_0\) 有限,为其中每个点补选一个覆盖开集,连同 \(U_0\) 即得有限子覆盖;但 \(A\) 未必闭。Hausdorff 假设正是为了排除这类病态。

    推论 5 在 Hausdorff 空间中,紧致 ⟹ 闭;若空间又紧致,则"闭"与"紧致"等价(结合定理 4)。特别地,从紧致 Hausdorff 空间到 Hausdorff 空间的连续双射自动是同胚。紧致 Hausdorff 空间还是正规的(两个不交闭集可用开集分离),这是测度论中 Riesz 表示定理等结果的空间基础。

    有限乘积:Tychonoff 定理¶

    定理 6(有限乘积紧致) 若 \(X_1, \dots, X_n\) 紧致,则 \(\prod X_i\)(带积拓扑)紧致。

    证明思想:先证两个因子的情形。设 \(\mathcal{U}\) 是 \(X \times Y\) 的开覆盖。对每个 \(x \in X\),薄片 \(\{x\} \times Y\) 紧致(同胚于 \(Y\)),故被 \(\mathcal{U}\) 的有限个子集覆盖;由积拓扑,存在 \(x\) 的邻域 \(W_x\) 使得 \(W_x \times Y\) 也被这有限个子集覆盖。\(\{W_x\}\) 覆盖紧致空间 \(X\),取有限个 \(W_{x_1}, \dots, W_{x_k}\),对应的有限个"薄片覆盖"合起来即覆盖 \(X \times Y\)。∎

    例 4 由定理 6,\(\mathbb{R}^n\) 中的闭方体 \([a_1, b_1] \times \cdots \times [a_n, b_n]\) 紧致;更一般地,紧致集的有限乘积紧致,这是 Heine–Borel 定理与多变量极值问题的几何基础。

    定理 7(Tychonoff 定理) 任意多个(含无穷个)紧致空间的乘积紧致。

    证明:需用选择公理,证明超出本页范围。Tychonoff 定理与选择公理等价,是现代拓扑学与泛函分析(如 Banach–Alaoglu 定理)的基石。∎

    度量空间中的紧致¶

    在度量空间中,紧致有几种互相等价的刻画,这让它既直观又实用。

    定理 8(度量空间的紧致刻画) 设 \((X, d)\) 是度量空间,以下条件等价:

    1. \(X\) 紧致;
    2. 序列紧致:\(X\) 的每个序列都有收敛子列;
    3. \(X\) 完备且完全有界(对任意 \(\varepsilon > 0\),\(X\) 能被有限个半径 \(\varepsilon\) 的开球覆盖)。

    证明思想:1 ⟹ 2 用有限交集性质或对角线论证;2 ⟹ 3 中完全有界由"若存在 \(\varepsilon\) 无有限球覆盖,则可造出无收敛子列的序列"得到,完备性由收敛子列推出;3 ⟹ 1 用 Lebesgue 数引理:完备 + 完全有界 ⟹ 每个开覆盖有正 Lebesgue 数,从而可抽取有限子覆盖。∎

    一般拓扑空间中这些等价失效

    序列紧致与紧致在一般拓扑空间中不等价:例如 \([0, 1]^{[0, 1]}\)(紧致,由 Tychonoff)中可构造无收敛子列的序列。这就是为什么现代拓扑学坚持用开覆盖定义紧致,而把序列版本降级为特例。度量空间原型的讨论见 实数的拓扑。

    命题 1(紧致 ⟹ 完备) 紧致度量空间是完备的。

    证明:设 \((x_n)\) 是 Cauchy 列。由定理 8 的序列紧致性,有收敛子列 \(x_{n_k} \to x\)。对 Cauchy 列 \((x_n)\),只要它有收敛子列,则自身收敛:取 \(n, n_k\) 都充分大,则 \(|x_n - x| \le |x_n - x_{n_k}| + |x_{n_k} - x| < \varepsilon\)。∎

    反之不成立:\(\mathbb{R}\) 完备却不紧致。由定理 8,紧致 = 完备 + 完全有界,可理解为"内部没有洞(完备)且规模有限(完全有界)"。特别地,紧致度量空间必有界:固定 \(x_0\),开球族 \(\{B(x_0, n)\}\) 覆盖 \(X\),取有限子覆盖即得界。注意"有界"只是紧致的必要条件——\((0, 1)\) 有界却不紧致。

    紧致在无穷维空间的失效

    在无穷维 Banach 空间中,闭单位球有界闭却不紧致(Riesz 引理):紧致性在无穷维中极其"稀缺",这是泛函分析中紧算子理论等许多困难的根源。有限维与无穷维的这条分界线,正是 Heine–Borel 定理(推论 1)的边界。

    一致连续:紧致性的分析回报¶

    定理 9(紧致集上连续 ⟹ 一致连续) 设 \(K \subset \mathbb{R}^n\) 紧致,\(f : K \to \mathbb{R}\) 连续。则 \(f\) 在 \(K\) 上一致连续:对任意 \(\varepsilon > 0\),存在 \(\delta > 0\) 使得 \(|x - y| < \delta\) 推出 \(|f(x) - f(y)| < \varepsilon\),且 \(\delta\) 与 \(x\) 无关。

    证明思想:连续只给出"对每个 \(x\) 有一个局部 \(\delta_x\)"。把开球族 \(\{B(x, \delta_x/2)\}\) 作为 \(K\) 的开覆盖,取有限子覆盖,取 \(\delta = \min \delta_{x_i}/2\)。有限个 \(\delta\) 的最小值 > 0,保证"同一 \(\delta\) 处处可用"。∎

    这是紧致性"把局部信息变成全局信息"的范本,也是 Riemann 积分理论中"可积函数有界"等结论的基础(参见 积分 与 实分析中的一致连续)。

    例 5 \(f(x) = 1/x\) 在 \((0, 1]\) 上连续但不一致连续:紧致性失效正是原因。\(f(x) = \sin x\) 在 \(\mathbb{R}\) 上一致连续,但 \(\mathbb{R}\) 并不紧致——紧致性给出充分条件而非必要条件。\(f(x) = \sqrt{x}\) 在 \([0, 1]\) 上一致连续(紧致);\(f(x) = x^2\) 在 \(\mathbb{R}\) 上不一致连续(斜率无界),但在任何紧区间 \([a, b]\) 上一致连续。

    紧致、连通与分析的三大基石

    极值定理依赖紧致,介值定理依赖连通(见 连通性)。二者合起来给出微积分中"闭区间上的连续函数"的全部基本性质,并各自推广到一般拓扑空间。紧致性与连通性互不蕴含:\(\mathbb{R}^n\) 中的紧致集(如圆周)可连通也可不连通(如两段相离的闭区间)。

    综合示例¶

    例 6(紧致性保证极值可达) 求 \(f(x) = \dfrac{x^2 - 1}{x^2 + 1}\) 在 \([0, 3]\) 上的最大值与最小值。

    解:\(f\) 连续、\([0, 3]\) 紧致,由推论 3 最值必达——先保证"存在",再动手求值。求导:

    \[ f'(x) = \frac{4x}{(x^2 + 1)^2}, \]

    \(f' = 0\) 仅当 \(x = 0\)。临界点与端点:\(f(0) = -1\),\(f(3) = \dfrac{8}{10} = \dfrac{4}{5}\)。故最小值为 \(-1\)(在 \(x = 0\) 处),最大值为 \(\dfrac{4}{5}\)(在 \(x = 3\) 处)。若定义域换成开区间 \((0, 3)\),\(f\) 仍连续却取不到最值——紧致性恰好是"极值必达"的拓扑保证。

    小结¶

    紧致性 = 每个开覆盖有有限子覆盖。它由 Heine–Borel 定理在 \(\mathbb{R}^n\) 中等价于"有界闭",通过连续映射保持,在 Hausdorff 空间中与"闭"建立联系,并给出极值定理与一致连续性。Tychonoff 定理把有限情形的结论推广到任意乘积,而度量空间中"紧致 ⟺ 序列紧致 ⟺ 完备 + 完全有界"给出实用的判别法。
