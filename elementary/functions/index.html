    初等数学

    函数¶

    函数是中学数学的核心内容。它刻画了两个变量之间"一个确定，另一个随之唯一确定"的依赖关系。理解函数的三要素、图象与性质，是后续学习方程、不等式、三角函数和数列的基础。

    函数的概念¶

    在一个变化过程中，有两个变量 \(x\) 和 \(y\)。如果对于 \(x\) 的每一个确定的值，\(y\) 都有唯一确定的值与它对应，那么就说 \(y\) 是 \(x\) 的函数，记作 \(y = f(x)\)，其中 \(x\) 叫做自变量，\(y\) 叫做因变量。

    从集合的角度看，函数是定义在数集上的一种特殊对应关系：设 \(A\)、\(B\) 是两个非空数集，如果按照某种对应法则 \(f\)，对于 \(A\) 中的每一个元素 \(x\)，在 \(B\) 中都有唯一确定的元素 \(y\) 与之对应，那么这种对应就叫从 \(A\) 到 \(B\) 的一个函数。

    例 1：\(y = 2x + 1\) 是一个函数，\(x\) 每取一个值，\(y\) 就有唯一的值与它对应，如 \(x = 3\) 时 \(y = 7\)。

    Note

    函数要求"一对一"或"多对一"的对应，不允许"一对多"。例如 \(y^2 = x\) 不是函数，因为 \(x = 4\) 时 \(y = \pm 2\)，一个 \(x\) 对应了两个 \(y\)。

    函数的三要素¶

    一个函数由三要素决定：

    1. 定义域：自变量 \(x\) 的取值范围，记作 \(D\)；
    2. 值域：因变量 \(y\) 的取值范围，即 \(\{f(x) \mid x \in D\}\)；
    3. 对应法则：\(x\) 与 \(y\) 之间的对应关系 \(f\)。

    两个函数相同，当且仅当它们的定义域和对应法则都相同。

    例 2：\(f(x) = x\) 与 \(g(x) = \dfrac{x^2}{x}\) 不是同一个函数。因为 \(f\) 的定义域是 \(\mathbb{R}\)，而 \(g\) 的定义域是 \(\{x \mid x \ne 0\}\)。

    Warning

    判断两个函数是否相同，不能只看解析式，还要看定义域。例如 \(y = \sqrt{x^2}\) 与 \(y = x\) 定义域相同但对应法则不同，也不是同一个函数。

    函数的表示方法¶

    函数通常有三种表示方法：

    • 解析式法：用数学式子表示，如 \(y = x^2 - 1\)；
    • 表格法：用表格列出部分 \(x\) 与 \(y\) 的对应值；
    • 图象法：在坐标系中描点画图，图象上每一点的横坐标与纵坐标就是一对对应值。

    三种方法各有优劣：解析式便于计算，表格直观，图象能整体反映函数的变化趋势。

    例 3：温度随时刻的变化常用表格或图象表示，而自由落体路程 \(s = \dfrac{1}{2}gt^2\) 则用解析式表示。

    定义域的常见限制¶

    求定义域时，要找出使表达式有意义的 \(x\) 的取值范围，常见的限制有：

    • 分母不能为零；
    • 偶次根号下的被开方数非负（即 \(\ge 0\)）；
    • 对数（高中阶段）的真数大于 \(0\)；
    • 实际问题还要考虑实际意义。

    例 4：求函数 \(f(x) = \dfrac{\sqrt{x - 1}}{x - 2}\) 的定义域。

    由 \(x - 1 \ge 0\) 得 \(x \ge 1\)，由 \(x - 2 \ne 0\) 得 \(x \ne 2\)。两者取交集，定义域为 \([1, 2) \cup (2, +\infty)\)。

    Warning

    求定义域时，分母限制、根号限制等条件必须同时满足，取交集；遗漏任何一个条件都会出错。

    函数的单调性¶

    设函数 \(y = f(x)\) 的定义域为 \(D\)，区间 \(I \subseteq D\)。如果对 \(I\) 内任意两个值 \(x_1 < x_2\)，都有 \(f(x_1) < f(x_2)\)，那么就说 \(f(x)\) 在区间 \(I\) 上是增函数；如果都有 \(f(x_1) > f(x_2)\)，就说 \(f(x)\) 在区间 \(I\) 上是减函数。增函数、减函数统称单调函数。

    从图象上看：增函数的图象从左到右上升，减函数的图象从左到右下降。

    例 5：\(f(x) = x^2\) 在 \((-\infty, 0)\) 上是减函数，在 \((0, +\infty)\) 上是增函数；\(f(x) = -2x\) 在 \(\mathbb{R}\) 上是减函数。

    Warning

    函数的单调性要指明所在区间。例如 \(f(x) = x^2\) 不能说"在 \(\mathbb{R}\) 上单调"，只能说它在 \((-\infty, 0]\) 上递减、在 \([0, +\infty)\) 上递增。

    函数的奇偶性¶

    设函数 \(f(x)\) 的定义域关于原点对称。

    • 如果对定义域内任意 \(x\)，都有 \(f(-x) = f(x)\)，则 \(f(x)\) 是偶函数，其图象关于 \(y\) 轴对称；
    • 如果对定义域内任意 \(x\)，都有 \(f(-x) = -f(x)\)，则 \(f(x)\) 是奇函数，其图象关于原点对称。

    例 6：\(f(x) = x^2\) 是偶函数，图象关于 \(y\) 轴对称；\(f(x) = x^3\) 是奇函数，图象关于原点对称；\(f(x) = x + 1\) 既不是奇函数也不是偶函数。

    Note

    判断奇偶性的前提是定义域关于原点对称。例如 \(f(x) = x^2\)，\(x \in [-1, 2]\)，定义域不对称，函数既非奇也非偶。

    常见函数的图象¶

    • 一次函数 \(y = kx + b\)（\(k \ne 0\)）：图象是直线。\(k > 0\) 时递增，\(k < 0\) 时递减，\(b\) 是纵截距。
    • 二次函数 \(y = ax^2 + bx + c\)（\(a \ne 0\)）：图象是抛物线。\(a > 0\) 时开口向上，\(a < 0\) 时开口向下；对称轴为 \(x = -\dfrac{b}{2a}\)。
    • 反比例函数 \(y = \dfrac{k}{x}\)（\(k \ne 0\)）：图象是双曲线，两支分别位于第一、三象限（\(k > 0\)）或第二、四象限（\(k < 0\)），且不与坐标轴相交。

    例 7：\(y = x^2 - 2x + 1\) 的对称轴为 \(x = 1\)，开口向上，顶点为 \((1, 0)\)。

    函数与方程的关系：零点¶

    使 \(f(x) = 0\) 成立的 \(x\) 的值叫做函数 \(f(x)\) 的零点。函数的零点就是方程 \(f(x) = 0\) 的实数根，也就是函数图象与 \(x\) 轴交点的横坐标。

    例 8：\(f(x) = x^2 - 3x + 2\) 的零点满足 \(x^2 - 3x + 2 = 0\)，解得 \(x = 1\) 或 \(x = 2\)，即零点为 \(1\) 和 \(2\)，图象与 \(x\) 轴交于 \((1, 0)\)、\((2, 0)\)。

    Warning

    零点是数，不是点。函数 \(f(x) = x^2 - 4\) 的零点是 \(2\) 和 \(-2\)，而不是点 \((2, 0)\) 与 \((-2, 0)\)。

    延伸阅读¶

    • 集合：定义域、值域都是集合，函数是数集间的对应关系。
    • 等式与方程：求零点就是解方程，函数与方程互相转化。
    • 不等式：用不等式描述定义域、值域与单调区间。
    • 函数概念与性质：在更高层次上研究函数的极限与连续性。
