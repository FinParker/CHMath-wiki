    几何

    初等几何¶

    几何学起源于丈量土地与建造房屋，而欧几里得在《几何原本》（约公元前 300 年）中开创性地用公理化方法组织全部几何知识：从少量公设出发，以演绎推理证明一切命题。这套体系统治了两千余年，其严格性与美感至今仍是数学的典范。本节回顾欧氏几何的基础：公设体系与平行公设的争议、三角形的全等与相似、勾股定理、三角形不等式、圆的基本性质、多边形内角和、常见图形的面积体积公式，并介绍解析几何的基本工具。平行公设的争议还催生了非欧几何，相关导航可参见几何。

    1. 欧几里得公理体系¶

    《几何原本》从五条公设（针对几何对象本身的构造规则）出发，辅以五条公理（关于"等量"的一般规则，如"等量加等量仍相等""等量减等量仍相等""整体大于部分"）。公设刻画"可以作出什么"，公理刻画"量的比较规则"，二者合起来构成整个体系的出发点。

    公设（欧几里得五公设）

    1. 从任意一点到任意一点可作一条直线段；
    2. 有限直线段可以连续延长成直线；
    3. 以任意点为圆心、任意长为半径可作一个圆；
    4. 所有直角都相等；
    5. 平行公设：若一条直线与两条直线相交，且同侧内角之和小于两直角，则这两条直线在该侧相交。（等价表述：过直线外一点，至多能作一条直线与该直线平行。）

    平行公设的争议 第五公设远比前四条复杂，两千余年间无数数学家试图"证明"它，均以失败告终。19 世纪，罗巴切夫斯基、鲍耶与黎曼等人发现：否定平行公设并不会导致矛盾，而会得到自洽而不同的几何——双曲几何与椭圆几何（统称非欧几何）。这一发现深刻地改变了数学观：公理不再被当作"自明的真理"，而只是形式系统的出发点。

    公理的地位

    现代数学把公理视为约定与出发点，而非不可置疑的真理。非欧几何的存在说明：平行公设只是区分不同几何的"开关"，欧氏几何是其中与我们日常直觉最吻合的一种。

    2. 三角形：全等与相似¶

    定义 1（三角形的分类） 三角形按角分为锐角三角形、直角三角形与钝角三角形；按边分为不等边三角形、等腰三角形与等边三角形（三边都相等的等腰三角形）。

    定理 1（三角形内角和） 任意三角形的三个内角之和为 \(180^\circ\)；三角形的外角等于与它不相邻的两个内角之和。

    证明 过顶点 \(A\) 作底边 \(BC\) 的平行线，利用平行线的同位角与内错角把三个内角拼成一个平角，即得 \(180^\circ\)。这也是定理 13 中 \(n = 3\) 情形的特例。

    定义 2（全等） 两个三角形能够完全重合（对应边相等、对应角相等），称为全等，记作 \(\triangle ABC \cong \triangle A'B'C'\)。

    定理 2（全等判定） 下列条件之一成立时，两个三角形全等：

    • SSS：三边对应相等；
    • SAS：两边及其夹角对应相等；
    • ASA：两角及其夹边对应相等；
    • AAS：两角及其中一角的对边对应相等。

    SSA 不能判定全等

    两边及其中一边的对角对应相等（SSA）不能判定全等：固定两边 \(a, b\) 与边 \(a\) 的对角，另一顶点可能有两个位置，产生"两解"歧义。直角三角形有特例：斜边与一条直角边对应相等（HL）可以判定全等。

    定义 3（相似） 形状相同、大小成比例的两个三角形称为相似，记作 \(\triangle ABC \sim \triangle A'B'C'\)。相似三角形对应角相等、对应边成比例，比例系数称为相似比 \(r\)，此时面积比为 \(r^2\)。

    定理 3（相似判定）

    • AA：两角对应相等（第三个角自动相等）；
    • SAS：两边对应成比例且夹角相等；
    • SSS：三边对应成比例。

    定理 4（勾股定理） 直角三角形的两条直角边 \(a, b\) 与斜边 \(c\) 满足

    \[ a^2 + b^2 = c^2. \]

    证明（面积拼接法） 作边长为 \(a + b\) 的大正方形，其面积 \((a + b)^2\) 可按如下方式分解：在四个角各放一个直角边为 \(a, b\)（斜边为 \(c\)）的直角三角形后，中央留下一个边长为 \(c\) 的正方形，故

    \[ (a + b)^2 = 4 \cdot \frac{ab}{2} + c^2. \]

    展开左端 \((a + b)^2 = a^2 + 2ab + b^2\) 并约去 \(2ab\)，即得 \(a^2 + b^2 = c^2\)。

    定理 5（勾股定理的逆定理） 若三角形三边满足 \(a^2 + b^2 = c^2\)，则边 \(c\) 所对的角为直角。逆定理提供了仅用三边长度判定直角的实用方法。

    定理 6（三角形不等式） 任意三角形两边之和大于第三边：

    \[ a + b > c, \qquad b + c > a, \qquad c + a > b, \]

    等价地，\(|a - b| < c\)。其几何意义是"两点之间直线最短"：折线必长于直线段。

    例 1 直角三角形两直角边为 \(3, 4\)，由勾股定理斜边为 \(c = \sqrt{3^2 + 4^2} = 5\)；反之，三边为 \(5, 12, 13\) 的三角形满足 \(5^2 + 12^2 = 13^2\)，由逆定理知它是直角三角形。这样的整数三元组称为勾股数。

    例 2 三根木条长度分别为 \(2, 3, 6\)，能否构成三角形？由三角形不等式，\(2 + 3 = 5 < 6\)，不满足两边之和大于第三边，故不能构成三角形。三条线段构成三角形的充要条件是"最长边小于其余两边之和"。

    3. 圆的基本性质¶

    定义 4（圆及其元素） 平面内到定点（圆心）距离等于定长（半径）的点的集合称为圆。连接圆上两点的线段称为弦；过圆心的弦称为直径；圆上两点间的部分称为弧；顶点在圆心的角称为圆心角；顶点在圆上、两边都与圆相交的角称为圆周角。

    定理 7（圆心角定理） 在同圆或等圆中，相等的圆心角所对的弧相等、所对的弦相等；反之，相等的弧（或弦）所对的圆心角相等。

    定理 8（圆周角定理） 一条弧所对的圆周角等于它所对的圆心角的一半。由此得两个重要推论：

    1. 同弧（或等弧）上的圆周角相等；
    2. 直径所对的圆周角是直角（半圆上的圆周角为 \(90^\circ\)）。

    例 3 以 \(BC\) 为直径作圆，圆上取一点 \(A\)（\(A \ne B, C\)），由推论 2 知 \(\angle BAC = 90^\circ\)，即 \(\triangle ABC\) 是直角三角形。反之，直角三角形的斜边就是其外接圆的直径。

    定义 5（切线） 与圆只有一个公共点的直线称为圆的切线，该公共点称为切点。

    定理 9（切线性质） 圆的切线垂直于过切点的半径；反之，过圆上一点且垂直于该点半径的直线是圆的切线。

    定理 10（切线长定理） 从圆外一点引圆的两条切线，两条切线长相等，且该点与圆心的连线平分两条切线所成的角。

    定理 11（弦切角定理） 弦切角（切线与过切点的弦所成的角）等于它所夹的弧所对的圆周角。

    定理 12（相交弦定理） 圆内两条弦 \(AB\) 与 \(CD\) 相交于点 \(P\)，则

    \[ PA \cdot PB = PC \cdot PD. \]

    即交点把两条弦分成的两段长度之积相等。可由连接端点后的相似三角形（\(\triangle PAC \sim \triangle PDB\)）直接推出。

    切线的判定与性质是互逆的

    判定"直线是切线"与性质"切线垂直于半径"互为逆命题，使用时注意方向：性质定理要求先知道切线，判定定理要求先证明垂直。

    4. 多边形与内角和¶

    定理 13（多边形内角和） \(n\) 边形（\(n \ge 3\)）的内角和为

    \[ S = (n - 2) \times 180^\circ. \]

    证明 从多边形的一个顶点出发作 \(n - 3\) 条对角线，把 \(n\) 边形分割成 \(n - 2\) 个三角形，每个三角形内角和为 \(180^\circ\)。

    定理 14（外角和） 任意凸多边形的外角和恒为 \(360^\circ\)，与边数无关。

    例 4 正 \(n\) 边形的每个内角为 \(\dfrac{(n-2) \times 180^\circ}{n}\)：正三角形 \(60^\circ\)，正方形 \(90^\circ\)，正五边形 \(108^\circ\)，正六边形 \(120^\circ\)。正六边形可以密铺平面，正是因为其内角 \(120^\circ\) 是 \(360^\circ\) 的约数。

    5. 面积与体积公式小结¶

    面积公式（二维）

    • 矩形：\(S = ab\)；
    • 平行四边形：\(S = \text{底} \times \text{高}\)；
    • 三角形：\(S = \dfrac{1}{2} \times \text{底} \times \text{高}\)；海伦公式 \(S = \sqrt{s(s-a)(s-b)(s-c)}\)，其中 \(s = \dfrac{a+b+c}{2}\) 为半周长；
    • 梯形：\(S = \dfrac{1}{2}(a + b) h\)；
    • 圆：\(S = \pi r^2\)；扇形（圆心角 \(\theta\) 弧度）：\(S = \dfrac{1}{2} r^2 \theta\)，弧长 \(l = r\theta\)；
    • 圆锥侧面积：\(S = \pi r l\)（\(l\) 为母线长）；球面：\(S = 4\pi r^2\)。

    体积公式（三维）

    • 柱体（棱柱、圆柱）：\(V = \text{底面积} \times \text{高}\)；
    • 锥体（棱锥、圆锥）：\(V = \dfrac{1}{3} \times \text{底面积} \times \text{高}\)；
    • 球：\(V = \dfrac{4}{3} \pi r^3\)。

    公式背后的统一原理

    锥体体积恒为同底等高柱体的 \(1/3\)，球体积等于其外切圆柱体积的 \(2/3\)（阿基米德，并刻于其墓碑）。这些公式在初等几何中靠实验与割补理解，严格推导需要定积分，可参见微积分基础。

    6. 解析几何入门¶

    解析几何（坐标几何）由笛卡尔创立，其思想是把几何对象翻译成坐标与方程，用代数方法处理几何问题——几何与代数的第一次大融合。

    在平面直角坐标系中，设两点 \(P_1(x_1, y_1)\) 与 \(P_2(x_2, y_2)\)。

    定理 15（两点间距离公式）

    \[ |P_1 P_2| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}. \]

    这正是勾股定理在坐标系中的体现：水平差与铅直差是直角边，两点连线是斜边。

    定理 16（中点公式） 线段 \(P_1 P_2\) 的中点坐标为

    \[ M = \left(\frac{x_1 + x_2}{2},\, \frac{y_1 + y_2}{2}\right). \]

    定义 6（直线的方程） 直线有若干常用表示：

    • 斜截式：\(y = kx + b\)，其中 \(k\) 为斜率，\(b\) 为纵截距；
    • 点斜式：\(y - y_0 = k(x - x_0)\)，过点 \((x_0, y_0)\)；
    • 一般式：\(Ax + By + C = 0\)（\(A, B\) 不同时为 0）；
    • 过两点 \(P_1, P_2\) 的斜率：\(k = \dfrac{y_2 - y_1}{x_2 - x_1}\)（\(x_1 \ne x_2\)）。

    定理 17（平行与垂直的斜率条件） 设两直线 \(y = k_1 x + b_1\) 与 \(y = k_2 x + b_2\)（斜率存在）：

    • 平行 \(\iff k_1 = k_2\)；
    • 垂直 \(\iff k_1 k_2 = -1\)。

    定理 18（点到直线的距离） 点 \((x_0, y_0)\) 到直线 \(Ax + By + C = 0\) 的距离为

    \[ d = \frac{|A x_0 + B y_0 + C|}{\sqrt{A^2 + B^2}}. \]

    定义 7（圆的标准方程） 圆心为 \((a, b)\)、半径为 \(r\) 的圆的方程为

    \[ (x - a)^2 + (y - b)^2 = r^2. \]

    圆上的点 \((x, y)\) 到圆心 \((a, b)\) 的距离恒为 \(r\)，这正是"到定点距离等于定长"的集合在坐标下的直接翻译。

    例 5 求过 \(P_1(1, 2)\) 与 \(P_2(3, 6)\) 的直线方程。斜率 \(k = \dfrac{6 - 2}{3 - 1} = 2\)，由点斜式得 \(y - 2 = 2(x - 1)\)，即 \(y = 2x\)。

    例 6 点 \((1, 2)\) 到直线 \(3x + 4y - 5 = 0\) 的距离为 \(d = \dfrac{|3 + 8 - 5|}{\sqrt{3^2 + 4^2}} = \dfrac{6}{5}\)。方程 \((x - 1)^2 + (y + 1)^2 = 9\) 表示圆心 \((1, -1)\)、半径 \(3\) 的圆。

    解析几何的深远影响

    距离、中点、直线与圆的方程是最基本的解析几何工具，它们把"图形"变成"方程"，把"证明"变成"计算"。向量与矩阵语言下的推广（直线、平面、线性方程组）属于线性代数的范畴，见线性代数。
