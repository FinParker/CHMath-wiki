# Hilbert 的 23 个问题

1900 年，David Hilbert 在巴黎国际数学家大会提出一组问题，其中演讲报告了 10 个，完整文本列出 23 个。这份清单覆盖集合论、数论、几何、分析、变分法与数学物理，深刻影响了二十世纪研究议程。

## 状态应如何理解

这些问题并不都适合简单标成“已解决/未解决”：有些得到肯定或否定答案，有些被证明独立于特定公理系统，有些表述宽泛而产生多个现代版本。以下只列代表性结果。

| 问题 | 主题 | 主要进展或当前理解 |
| --- | --- | --- |
| 1 | 连续统假设 | Gödel 与 Cohen 证明它相对于 ZFC 具有独立性 |
| 2 | 算术公理的一致性 | Gödel 第二不完备定理限制了原计划；Gentzen 给出使用超限归纳的相对一致性证明 |
| 3 | 等体积多面体的剪拼 | Dehn 构造不变量并给出否定答案 |
| 7 | $\alpha^\beta$ 的超越性 | Gelfond–Schneider 定理解决 |
| 8 | Riemann 假设与质数问题 | Riemann 假设仍未解决 |
| 10 | Diophantine 方程的判定算法 | Matiyasevich–Robinson–Davis–Putnam 定理证明不存在这样的通用算法 |
| 18 | 空间镶嵌与球堆积 | 包含多个部分；Kepler 猜想已由 Hales 等完成证明并形式化验证 |
| 21 | 给定单值群的线性微分方程 | 原始普遍表述存在反例，需附加条件 |

Hilbert 问题的重要性也在方法论：它展示了一个清晰、困难且可传承的问题清单如何组织跨世代研究。2000 年公布的千禧年大奖难题延续了这种传统。
