# 数学史与数学问题

> 数学史不只是人物与年代的清单。概念常在计算需要、证明标准和基础危机之间逐步形成；未解问题则标出当前理论的边界。

## 如何阅读数学史

1. 区分“首次发现”“首次证明”“首次发表”和“现代形式”，它们可能属于不同人物与年代。
2. 避免把数学发展写成单一文明的直线接力；不同地区常有独立传统和长期交流。
3. 所谓“三次数学危机”是中文教学中的常见叙事框架，并非数学史界唯一的分期方法。
4. 对未解问题只采纳专业共同体确认的结果；预印本、自称证明与新闻报道不等于问题已解决。
