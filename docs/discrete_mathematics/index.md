# 离散数学

> 离散数学研究可数、分离的对象：组合计数、图结构、形式语言与自动机。
> 它是计算机科学的数学基础，也与代数、数论、逻辑学深度交叉。

## 内容地图

- [组合数学](combinatorics.md) — 计数原理、排列组合、生成函数。
- [图论](graph_theory.md) — 图、树、欧拉/哈密顿、匹配、图着色。
- [自动机理论](automata_theory.md) — 有限自动机、正则语言、上下文无关语言。
