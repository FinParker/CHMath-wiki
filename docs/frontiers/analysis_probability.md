# 分析、概率与方程前沿

## 几何分析

几何分析（geometric analysis）用 PDE 和变分法研究几何结构。Ricci flow、mean curvature flow、minimal surfaces 和 gauge theory 都把几何对象随方程演化。奇点如何形成、怎样分类与延拓，是许多问题的中心。

当前研究包括高维流形的曲率约束、奇异空间、几何流的弱解与手术，以及 general relativity 中的质量、黑洞和时空稳定性问题。

## 湍流与非线性 PDE

Navier–Stokes 方程的三维全局正则性仍是千禧年难题。现代研究也关注 Euler 方程的低正则解、Onsager conjecture 所揭示的 anomalous dissipation，以及 convex integration 构造出的非唯一性现象。

这些结果改变了对“解”的理解：存在弱解并不必然给出唯一、平滑或物理可接受的动力学。研究前沿因此同时涉及正则性、唯一性、耗散选择原则和统计湍流。

## Stochastic PDE 与 KPZ

随机偏微分方程（stochastic partial differential equations, SPDE）把空间—时间噪声加入演化方程。许多非线性方程中的乘积在经典函数意义下并不存在，需要 regularity structures、paracontrolled distributions 等重整化工具。

KPZ equation 描述随机界面增长，是 universality 的代表模型。核心问题包括不同微观模型为何产生相同尺度指数、非平衡涨落的精确分布，以及高维情形的适定性。

## Optimal transport

最优输运（optimal transport）研究以最小代价把一个概率分布搬运成另一个分布。Wasserstein 距离把概率测度空间变成几何空间，使某些扩散 PDE 可理解为 entropy 的 gradient flow。

当前连接包括生成模型、统计估计、inverse problems、Ricci curvature 的综合定义、mean-field limits 和多主体系统。计算上，entropic regularization 与 Sinkhorn algorithm 使大规模近似成为可能，但偏差、维数灾难和统计稳定性仍是活跃问题。
