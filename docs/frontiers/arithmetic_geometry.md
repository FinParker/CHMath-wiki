# 算术几何与 Langlands 纲领

## 一张“对应关系之网”

Langlands 纲领（Langlands program）试图联系两类看似不同的对象：一边是 Galois representations 和数域的算术信息，另一边是 automorphic forms 与表示论。它不是单个猜想，而是包含互反性、函子性、$L$-函数和局部—整体关系的大型研究计划。

核心愿景可以粗略写成

$$\text{Galois / arithmetic data}\quad\longleftrightarrow\quad\text{automorphic / representation data}.$$

Fermat 大定理的证明使用 modularity 的重要特例；Ngô Bảo Châu 对 fundamental lemma 的证明则推进了 trace formula 路线。一般函子性和许多高维对应仍是开放研究。

## 几何 Langlands 的 2024 年突破

几何 Langlands（geometric Langlands）把数域换成代数曲线的函数域，并把函数或表示提升为 sheaf 与 category。2024 年，Arinkin、Beraldo、Campbell、Chen、Faergeman、Gaitsgory、Lin、Raskin、Rozenblyum 等人在五篇论文中给出了**范畴化、整体、无分歧几何 Langlands 猜想**的证明。

这个成果是 Langlands 纲领中的重大里程碑，但不表示经典算术 Langlands、所有 ramified/local 版本或全部相关猜想已经解决。当前研究还包括推广范围、简化证明、与量子场论及表示论的进一步联系。

## Perfectoid geometry

Peter Scholze 于 2012 年前后引入 perfectoid spaces。其 tilting correspondence 能在混合特征 $0/p$ 与特征 $p$ 之间转移某些几何问题，使 Frobenius 方法可用于原本难以处理的 $p$-adic 对象。

它已经影响 $p$-adic Hodge theory、Shimura varieties、Galois representations、交换代数和代数拓扑。perfectoid 方法与 Fargues–Fontaine curve 也为局部 Langlands 的几何化提供新框架。

## Prismatic cohomology

Bhatt 与 Scholze 建立的 prismatic cohomology 统一并比较多种 $p$-adic 上同调理论。研究焦点包括 prisms 与 $F$-crystals、积分 $p$-adic Hodge theory、奇异或混合特征空间，以及与 algebraic $K$-theory 的关系。

## 当前问题

- Langlands functoriality 的一般构造与证明；
- $p$-adic Langlands 在高维群上的推广；
- torsion automorphic forms 与 Galois representations；
- 几何 Langlands 的 ramified、quantum 和 local 版本；
- prismatic 与其他 cohomology 理论的结构和计算。
