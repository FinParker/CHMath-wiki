# 数学与交叉学科

> 数学为不同学科提供表示结构、描述变化、处理不确定性和优化决策的共同语言；现实问题也会反过来产生新的数学对象与理论。

## 交叉学科共享的数学

| 数学工具 | 回答的问题 | 典型应用 |
| --- | --- | --- |
| 线性代数与谱理论 | 哪些方向、模态或低维结构最重要 | 量子态、振动、PCA、网络中心性、推荐系统 |
| ODE、PDE 与动力系统 | 系统怎样随时间和空间演化 | 轨道、波与扩散、化学反应、疾病传播、气候 |
| 概率与统计 | 噪声下能推断什么、不确定性多大 | 实验、临床试验、金融风险、传感器、机器学习 |
| 优化与变分法 | 在约束下怎样选择、设计或反演 | 控制、资源配置、成像、参数估计、模型训练 |
| 图论与网络 | 相互作用结构怎样影响整体行为 | 分子、互联网、交通、供应链、社会网络 |
| 几何、拓扑与群论 | 形状、对称性和不变量是什么 | 相对论、材料、机器人、数据分析、场论 |
| 数值分析与科学计算 | 连续模型怎样可靠地变成计算 | 数值 PDE、模拟、数据同化、数字孪生 |

数学工具并不自动保证模型正确。同一个方程可以描述不同机制，同一组数据也可能支持多个模型。交叉研究必须同时说明对象、尺度、参数来源、观测过程与验证标准。

## 从现实问题到数学结论

一个可检查的建模循环（modeling cycle）通常包含：

1. **定义问题**：明确系统边界、时间尺度、空间尺度和需要预测的量；
2. **选择状态与假设**：决定哪些变量保留，哪些相互作用被忽略；
3. **建立模型**：使用守恒律、概率机制、优化目标或网络结构；
4. **分析与计算**：研究存在性、稳定性、可辨识性、误差和算法复杂度；
5. **校准与验证**：把参数估计与独立数据验证分开，检查残差和外推性能；
6. **修正模型**：根据失败模式增加机制，或删除无法由数据支持的复杂度。

模型验证（validation）回答模型是否足以描述目标现象；数值验证（verification）回答程序是否正确求解了所写方程。两者不能互相替代。

## 三种常见模型

- **机制模型**（mechanistic model）：从守恒律、相互作用或微观规则推导，较容易解释，但可能遗漏机制；
- **统计模型**（statistical model）：从随机变量与数据分布描述关系，能量化不确定性，但相关性不自动成为因果；
- **数据驱动模型**（data-driven model）：从大量数据学习映射，表达能力强，但需要处理分布漂移、可解释性和约束违反。

混合模型（hybrid model）把物理规律、统计推断和机器学习结合起来。关键问题不是“哪一种永远最好”，而是目标、数据、误差容忍度和可验证条件是否匹配。
