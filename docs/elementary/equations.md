# 等式与方程

方程是含有未知数的等式，是刻画数量关系、求未知量的基本工具。从一元一次方程到一元二次方程、方程组和分式方程，解方程的核心思想始终是"变形化简，逐步求出未知数"。

## 方程的概念与解

含有未知数的**等式**叫做**方程**，如 $3x + 5 = 14$、$x^2 - 4 = 0$。能使方程左右两边相等的未知数的值，叫做方程的**解**；求方程解的过程叫做**解方程**。

等式的两个基本性质是解方程的依据：

1. 等式两边同时加上（或减去）同一个数，等式仍然成立；
2. 等式两边同时乘（或除以）同一个非零数，等式仍然成立。

**例 1**：判断 $x = 3$ 是否是方程 $2x + 1 = 7$ 的解。代入得 $2 \times 3 + 1 = 7$，成立，所以 $x = 3$ 是方程的解。

## 一元一次方程

只含一个未知数，并且未知数的次数是 $1$ 的方程叫做**一元一次方程**，一般形式为 $ax + b = 0$（$a \ne 0$）。解法步骤：

1. 去分母（两边同乘各分母的最小公倍数）；
2. 去括号；
3. **移项**（把含未知数的项移到左边，常数项移到右边，移项要变号）；
4. 合并同类项；
5. 系数化为 $1$（两边同除以未知数的系数）。

**例 2**：解方程 $3x + 5 = 14$。

移项得 $3x = 14 - 5 = 9$，两边同除以 $3$，得 $x = 3$。

!!! warning
    移项必须**变号**：从等号一边移到另一边，加变减、减变加。例如解 $x + 5 = 14$ 时，$+5$ 移到右边变成 $-5$，得 $x = 14 - 5$。

## 一元二次方程

只含一个未知数，并且未知数的最高次数是 $2$ 的方程叫做**一元二次方程**，一般形式为 $ax^2 + bx + c = 0$（$a \ne 0$）。常用的解法有：

- **配方法**：通过配方把方程化为 $(x + m)^2 = n$ 的形式再开平方；
- **公式法**：用求根公式直接求解；
- 因式分解法（适用于容易分解的情形）。

**求根公式**：一元二次方程 $ax^2 + bx + c = 0$（$a \ne 0$）的解为

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}.$$

**例 3**：用公式法解方程 $x^2 - 4x + 1 = 0$。

这里 $a = 1$，$b = -4$，$c = 1$，代入求根公式得

$$x = \frac{4 \pm \sqrt{16 - 4}}{2} = \frac{4 \pm 2\sqrt{3}}{2} = 2 \pm \sqrt{3}.$$

### 判别式与根的关系

$\Delta = b^2 - 4ac$ 叫做方程根的**判别式**，它决定根的个数：

- $\Delta > 0$：方程有两个不相等的实数根；
- $\Delta = 0$：方程有两个相等的实数根；
- $\Delta < 0$：方程没有实数根（初中阶段即认为无解）。

**例 4**：方程 $x^2 + x + 1 = 0$ 中，$\Delta = 1 - 4 = -3 < 0$，没有实数根。

!!! warning
    使用求根公式前，必须先把方程化为一般形式 $ax^2 + bx + c = 0$，并确保 $a \ne 0$。系数带负号时，代入公式要注意符号，如 $b = -4$ 时 $-b = 4$。

### 韦达定理（根与系数的关系）

如果一元二次方程 $ax^2 + bx + c = 0$（$a \ne 0$）的两个根为 $x_1$、$x_2$，那么

$$x_1 + x_2 = -\frac{b}{a}, \qquad x_1 x_2 = \frac{c}{a}.$$

**例 5**：方程 $x^2 - 5x + 6 = 0$ 的两个根之和为 $5$，两根之积为 $6$，所以两根是 $2$ 和 $3$。韦达定理常用于不解方程求对称式的值，如 $x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2$。

## 二元一次方程组

含有两个未知数，并且含未知数的项的次数都是 $1$ 的两个方程合在一起，组成**二元一次方程组**。解方程组的基本思想是**消元**，即把"二元"化为"一元"，常用方法：

- **代入消元法**：把一个方程变形，用含一个未知数的式子表示另一个未知数，再代入另一个方程；
- **加减消元法**：把两个方程相加或相减（可先乘适当倍数），消去一个未知数。

**例 6**：解方程组 $\begin{cases} x + y = 5 \\ x - y = 1 \end{cases}$。

两式相加得 $2x = 6$，$x = 3$；代入 $x + y = 5$ 得 $y = 2$。所以方程组的解为 $\begin{cases} x = 3 \\ y = 2 \end{cases}$。

!!! note
    方程组的解必须同时满足每一个方程，所以检验时要把解代回**所有**方程逐一验证。

## 分式方程

分母中含有未知数的方程叫做**分式方程**，如 $\dfrac{1}{x} + \dfrac{2}{x + 1} = 1$。解分式方程的步骤：

1. 去分母：两边同乘最简公分母，化为整式方程；
2. 解这个整式方程；
3. **验根**：把解代入最简公分母，若公分母为零，则是**增根**，必须舍去。

**例 7**：解方程 $\dfrac{1}{x} + \dfrac{2}{x + 1} = 1$。

两边同乘 $x(x + 1)$，得 $(x + 1) + 2x = x(x + 1)$，整理得 $x^2 - 2x - 1 = 0$，解得 $x = 1 \pm \sqrt{2}$。代入公分母 $x(x + 1)$，两解均不为零，都不是增根，所以原方程的解为 $x = 1 + \sqrt{2}$ 或 $x = 1 - \sqrt{2}$。

!!! warning
    去分母时可能引入使分母为零的**增根**，因此分式方程**必须验根**，这一步不能省略。验根的方法是把解代入最简公分母，公分母为零的解要舍去。
