# 初等数论

初等数论研究整数的性质，特别是整除、因数与倍数、质数等问题。它不依赖高等数学工具，却能培养严谨的推理习惯，是竞赛数学和数论学习的起点。

## 因数与倍数

设 $a$、$b$ 是整数，且 $b \ne 0$。如果存在整数 $k$，使得 $a = bk$，就说 $b$ **整除** $a$（记作 $b \mid a$），$b$ 叫做 $a$ 的**因数**（约数），$a$ 叫做 $b$ 的**倍数**。

**例 1**：因为 $12 = 3 \times 4$，所以 $3 \mid 12$、$4 \mid 12$，$3$ 和 $4$ 都是 $12$ 的因数，$12$ 是 $3$ 和 $4$ 的倍数。

!!! note
    整除中 $b \ne 0$，且"整除"与"被整除"要分清：$3 \mid 12$ 读作"$3$ 整除 $12$"，即 $12$ 是 $3$ 的倍数。

## 质数与合数

大于 $1$ 的自然数，如果只有 $1$ 和它本身两个因数，就叫做**质数**（素数）；如果除了 $1$ 和它本身以外还有其他因数，就叫做**合数**。$1$ 既不是质数也不是合数。

**例 2**：$2, 3, 5, 7, 11$ 都是质数；$4, 6, 8, 9, 10$ 都是合数。

!!! warning
    $2$ 是唯一的偶质数，也是最小的质数。$1$ 不是质数也不是合数，判断时要特别小心。

## 整除判定

常用的整除判定方法：

- 能被 $2$ 整除：末位数字是偶数（$0, 2, 4, 6, 8$）；
- 能被 $3$ 整除：各位数字之和能被 $3$ 整除；
- 能被 $5$ 整除：末位数字是 $0$ 或 $5$；
- 能被 $9$ 整除：各位数字之和能被 $9$ 整除。

**例 3**：判断 $3456$ 能否被 $3$、$9$ 整除。

$3 + 4 + 5 + 6 = 18$，$18$ 能被 $3$ 整除也能被 $9$ 整除，所以 $3456$ 既能被 $3$ 整除也能被 $9$ 整除。

!!! note
    能被 $3$ 整除的数不一定能被 $9$ 整除。例如 $15$：$1 + 5 = 6$ 能被 $3$ 整除，但 $6$ 不能被 $9$ 整除，所以 $15$ 能被 $3$ 整除但不能被 $9$ 整除。

## 最大公约数与最小公倍数

几个数**公有的因数**中最大的一个，叫做它们的**最大公约数**（最大公因数），记作 $\gcd(a, b)$；几个数**公有的倍数**中最小的一个，叫做它们的**最小公倍数**，记作 $\operatorname{lcm}(a, b)$。

求最大公约数常用**短除法**：把几个数并排，用它们的公有质因数逐次相除，直到商互质为止，所有除数相乘就是最大公约数；再乘上最后互质的商，就是最小公倍数。

**例 4**：用短除法求 $12$ 与 $18$ 的最大公约数和最小公倍数。

$12$ 与 $18$ 先同除以 $2$ 得 $6$ 与 $9$，再同除以 $3$ 得 $2$ 与 $3$（互质）。所以

$$\gcd(12, 18) = 2 \times 3 = 6, \qquad \operatorname{lcm}(12, 18) = 2 \times 3 \times 2 \times 3 = 36.$$

最大公约数与最小公倍数之间满足关系：

$$\gcd(a, b) \times \operatorname{lcm}(a, b) = a \times b.$$

!!! warning
    短除法要除到最后的商**互质**为止，只除到"不能再整除"是不够的。例如 $12$ 与 $18$ 若只除以 $2$ 得到 $6$ 与 $9$，$6$ 与 $9$ 还有公因数 $3$，还需继续除。

## 互质

如果两个数的最大公约数是 $1$，就称这两个数**互质**（互素）。例如 $8$ 与 $15$ 互质，$7$ 与 $11$ 互质。

**例 5**：判断 $14$ 与 $25$ 是否互质。

$14 = 2 \times 7$，$25 = 5^2$，没有公共质因数，所以 $\gcd(14, 25) = 1$，两数互质。

## 唯一分解定理

任何一个大于 $1$ 的自然数，都可以写成若干个质数相乘的形式，并且如果不计质数的书写顺序，这种写法是**唯一**的。这就是算术基本定理（中学表述为**唯一分解定理**）。例如

$$360 = 2^3 \times 3^2 \times 5.$$

把数分解为质因数乘积，是求最大公约数、最小公倍数和判断整除性的有力工具。

**例 6**：用分解质因数法求 $360$ 与 $84$ 的最大公约数。

$360 = 2^3 \times 3^2 \times 5$，$84 = 2^2 \times 3 \times 7$。取公共质因数的较低次幂：$2^2 \times 3 = 12$，所以 $\gcd(360, 84) = 12$。

!!! note
    中学阶段常用短除法完成质因数分解：用质数 $2, 3, 5, 7, \dots$ 依次试除，直到商为 $1$ 为止，所有除数连乘就是原数的分解。

## 完全平方数

能写成某个整数的平方的数叫做**完全平方数**，如 $1, 4, 9, 16, 25, \dots$。完全平方数有下列特征：

- 末位数字只可能是 $0, 1, 4, 5, 6, 9$，不可能以 $2, 3, 7, 8$ 结尾；
- 完全平方数开平方后是整数。

**例 7**：判断 $2024$ 是不是完全平方数。

$2024$ 的末位是 $4$，符合末位条件，但 $44^2 = 1936 < 2024 < 45^2 = 2025$，不在两个相邻平方数之间，所以 $2024$ 不是完全平方数。

!!! warning
    末位数字符合条件只是完全平方数的**必要**条件，不是充分条件。例如 $14$ 的末位是 $4$，但 $14$ 不是完全平方数，必须进一步检验。
