# 初等数学

> 本节系统整理初中与高中数学。它既可以作为中学阶段的自学路线，也可以作为进入[数学基础](../foundations/index.md)、[代数](../algebra/index.md)和[分析](../analysis/index.md)前的知识检查表。

## 按学段学习

### [初中数学](junior_high.md)

从具体计算走向符号推理，内容包括数与式、方程与不等式、基本函数、平面几何、数据分析与概率。完成这一部分后，应能熟练进行代数变形，并能书写基本的几何证明。

推荐顺序：

1. [初中数学总览](junior_high.md)
2. [等式与方程](equations.md)
3. [初等数论](number_theory.md)
4. [函数](functions.md)与[不等式](inequalities.md)
5. [初等几何](../geometry/elementary.md)

### [高中数学](senior_high.md)

以函数为主线，进一步学习集合与逻辑、三角函数、向量、数列、解析几何、立体几何、概率统计与导数初步。这些内容是大学数学的直接预备知识。

推荐顺序：

1. [高中数学总览](senior_high.md)
2. [集合](sets.md)、[简单逻辑](logic.md)与[函数](functions.md)
3. [不等式](inequalities.md)、[三角函数](trigonometry.md)与[数列](sequences.md)
4. [圆锥曲线](../geometry/conic_sections.md)
5. [概率与统计](../probability_statistics/index.md)和[微积分](../analysis/calculus/index.md)

## 怎样使用本节

- 按学段系统学习时，从对应的总览页开始，再进入各专题。
- 查漏补缺时，直接使用上面的专题索引；每篇末尾都有后续内容链接。
- 准备大学数学时，重点检查函数、逻辑、不等式、三角函数、数列和解析几何。
