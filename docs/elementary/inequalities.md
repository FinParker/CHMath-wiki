# 不等式

不等式用符号 $<$, $>$, $\le$, $\ge$ 表示两个量之间的大小关系，是刻画"范围"与"约束"的基本工具。解不等式与解方程一样重要，其解集通常用集合或区间表示。

## 不等式的基本性质

设 $a$、$b$、$c$ 为实数，不等式有以下基本性质：

1. **传递性**：若 $a < b$ 且 $b < c$，则 $a < c$；
2. **加法性质**：若 $a < b$，则 $a + c < b + c$（不等式两边同加一个数，不等号方向不变）；
3. **乘法性质**：若 $a < b$ 且 $c > 0$，则 $ac < bc$；若 $a < b$ 且 $c < 0$，则 $ac > bc$（两边同乘负数，不等号**反向**）；
4. 同向不等式可相加：若 $a < b$ 且 $c < d$，则 $a + c < b + d$。

**例 1**：由 $-3 < 2$，两边同乘 $-1$，得 $3 > -2$，不等号方向改变了。

!!! warning
    两边同乘（或同除）一个**负数**时，不等号必须反向，这是解不等式时最常见的错误。同乘正数时方向不变。

## 一元一次不等式

只含一个未知数，并且未知数的最高次数是 $1$ 的不等式叫做**一元一次不等式**，如 $2x + 3 > 7$。解一元一次不等式的一般步骤：

1. 去分母、去括号；
2. 移项（把含未知数的项移到左边，常数项移到右边）；
3. 合并同类项；
4. 系数化为 $1$（注意系数为负时不等号反向）。

**例 2**：解不等式 $2x + 3 > 7$。

移项得 $2x > 4$，两边同除以 $2$ 得 $x > 2$。解集为 $\{x \mid x > 2\}$，即 $(2, +\infty)$。

## 一元二次不等式

形如 $ax^2 + bx + c > 0$（或 $< 0$，$\ge 0$，$\le 0$，其中 $a \ne 0$）的不等式叫做**一元二次不等式**。先解对应方程 $ax^2 + bx + c = 0$ 得根，再结合二次函数 $y = ax^2 + bx + c$ 的开口方向判断：

- 当 $a > 0$ 时，抛物线开口向上，图象在 $x$ 轴上方的部分对应 $ax^2 + bx + c > 0$；
- 当 $a < 0$ 时，抛物线开口向下，情况相反。

**例 3**：解不等式 $x^2 - x - 6 > 0$。

方程 $x^2 - x - 6 = 0$ 的根为 $x = -2$ 或 $x = 3$。因为 $a = 1 > 0$，开口向上，所以解集为 $\{x \mid x < -2 \text{ 或 } x > 3\}$。

!!! note
    解一元二次不等式时，先看二次项系数：若 $a < 0$，可两边同乘 $-1$ 化为 $a > 0$ 的情形，再按"大于取两边、小于取中间"的规律写出解集。

## 分式不等式

分母中含有未知数的不等式叫做**分式不等式**，如 $\dfrac{x + 1}{x - 2} > 0$。解分式不等式时，先把所有项移到一边、通分成一个分式，再等价转化为整式不等式（注意分母不能为零）。

**例 4**：解不等式 $\dfrac{x + 1}{x - 2} > 0$。

分式大于 $0$，等价于分子、分母同号，即 $(x + 1)(x - 2) > 0$，解得 $x < -1$ 或 $x > 2$。解集为 $(-\infty, -1) \cup (2, +\infty)$。

!!! warning
    分式不等式**不能**直接两边同乘分母，因为分母的符号不确定。应通过移项通分，转化为整式不等式求解，并排除使分母为零的 $x$。

## 绝对值不等式

形如 $|x| < a$ 或 $|x| > a$（$a > 0$）的不等式叫做**绝对值不等式**，其解为：

$$|x| < a \iff -a < x < a, \qquad |x| > a \iff x < -a \text{ 或 } x > a.$$

几何意义是：数轴上到原点距离小于 $a$（或大于 $a$）的点。

**例 5**：解不等式 $|2x - 1| \le 3$。

由 $-3 \le 2x - 1 \le 3$，得 $-2 \le 2x \le 4$，即 $-1 \le x \le 2$。解集为 $[-1, 2]$。

!!! warning
    解 $|x| > a$ 型不等式时，解集是**两个区间取并集**（$x < -a$ 或 $x > a$），不要误写成 $-a < x$ 与 $x < a$ 的交集。

## 均值不等式

对任意正数 $a$、$b$，有

$$\frac{a + b}{2} \ge \sqrt{ab},$$

即 $a + b \ge 2\sqrt{ab}$，当且仅当 $a = b$ 时取等号。这就是**均值不等式**（又称基本不等式）：两个正数的算术平均数不小于它们的几何平均数。

均值不等式常用于求最值：若 $a$、$b$ 为正数且 $a + b$ 为定值，则当 $a = b$ 时 $ab$ 最大；若 $ab$ 为定值，则当 $a = b$ 时 $a + b$ 最小。口诀是"一正、二定、三相等"。

**例 6**：已知 $x > 0$，求 $x + \dfrac{4}{x}$ 的最小值。

由均值不等式，$x + \dfrac{4}{x} \ge 2\sqrt{x \cdot \dfrac{4}{x}} = 4$，当 $x = \dfrac{4}{x}$，即 $x = 2$ 时取等号。所以最小值为 $4$。

!!! warning
    使用均值不等式求最值，必须先确认两数均为**正数**，且等号能取到（即"一正、二定、三相等"三个条件缺一不可）。

## 不等式组

几个不等式联立在一起就是**不等式组**，其解集是各个不等式解集的**交集**。解不等式组的一般步骤：先分别解出每个不等式，再在数轴上找公共部分。

**例 7**：解不等式组 $\begin{cases} x + 1 > 0 \\ x - 3 < 0 \end{cases}$。

第一个不等式得 $x > -1$，第二个得 $x < 3$，公共部分为 $-1 < x < 3$，即解集为 $(-1, 3)$。
