# 集合

集合是中学数学中最基本的语言工具。它把"一组确定的、彼此不同的对象"看成一个整体，用来描述方程的解、函数的定义域、图形上的点等。掌握集合的表示、关系与运算，是学习函数、不等式和概率统计的基础。

## 集合的概念与元素

把一些确定的对象放在一起，就组成一个**集合**（set），简称**集**。组成集合的每个对象叫做这个集合的**元素**（element）。

**例 1**：方程 $x^2 - 4 = 0$ 的解构成一个集合，它的元素是 $-2$ 和 $2$。

元素与集合的关系用符号表示：

- 如果 $a$ 是集合 $A$ 的元素，记作 $a \in A$，读作"$a$ 属于 $A$"；
- 如果 $a$ 不是集合 $A$ 的元素，记作 $a \notin A$，读作"$a$ 不属于 $A$"。

**例 2**：设 $A = \{1, 2, 3\}$，则 $2 \in A$，而 $5 \notin A$。

集合中的元素有三个基本特点：

1. **确定性**：任意一个对象，要么属于这个集合，要么不属于，不能模棱两可；
2. **互异性**：同一个集合中的元素互不相同，重复的元素只算一个；
3. **无序性**：集合中元素的排列顺序不影响集合本身，如 $\{1, 2\}$ 与 $\{2, 1\}$ 表示同一个集合。

!!! note
    由于互异性，写 $\{1, 1, 2\}$ 时应化简为 $\{1, 2\}$。

## 集合的表示方法

常用的表示方法有两种：

- **列举法**：把元素一一列出，用花括号括起来。如 $A = \{1, 2, 3, 4\}$。
- **描述法**：用元素满足的条件来描述。如 $B = \{x \mid x > 3\}$，读作"满足 $x > 3$ 的实数 $x$ 的集合"；又如 $C = \{x \mid x \text{ 是小于 } 10 \text{ 的质数}\}$。

**区间**是一种用不等式描述实数集合的简便写法：

- 闭区间 $[a, b] = \{x \mid a \le x \le b\}$；
- 开区间 $(a, b) = \{x \mid a < x < b\}$；
- 半开半闭区间 $[a, b)$、$(a, b]$ 类似，端点处的开闭要看清。

!!! warning
    区间端点用圆括号还是方括号，决定了端点是否取到。例如 $x > 3$ 写成 $(3, +\infty)$，而 $x \ge 3$ 写成 $[3, +\infty)$，两者含义不同。

## 常见数集

中学常用的数集及其记号如下：

| 记号 | 名称 | 含义 |
| --- | --- | --- |
| $\mathbb{N}$ | 自然数集 | 全体自然数，如 $0, 1, 2, \dots$ |
| $\mathbb{N}^*$ 或 $\mathbb{N}_+$ | 正整数集 | 正整数 $1, 2, 3, \dots$ |
| $\mathbb{Z}$ | 整数集 | 整数 $\dots, -2, -1, 0, 1, 2, \dots$ |
| $\mathbb{Q}$ | 有理数集 | 能写成分数的数 |
| $\mathbb{R}$ | 实数集 | 有理数与无理数的全体 |

它们之间满足包含关系：$\mathbb{N}^* \subset \mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$。

## 有限集、无限集与空集

- **有限集**：含有有限个元素的集合。如 $\{1, 2, 3\}$。
- **无限集**：含有无限个元素的集合。如自然数集 $\mathbb{N}$、实数集 $\mathbb{R}$。
- **空集**：不含任何元素的集合，记作 $\varnothing$。如方程 $x^2 + 1 = 0$ 在实数范围内的解集是空集。

!!! warning
    空集 $\varnothing$ 不是 $\{0\}$。$\{0\}$ 含有一个元素 $0$，是有限集；$\varnothing$ 不含任何元素。也要注意 $\varnothing$ 与 $\{\varnothing\}$ 的区别。

## 集合的基本关系

### 子集与真子集

如果集合 $A$ 的每一个元素都是集合 $B$ 的元素，就说 $A$ 是 $B$ 的**子集**，记作 $A \subseteq B$（读作"$A$ 包含于 $B$"），也说 $B \supseteq A$。

如果 $A \subseteq B$，且 $B$ 中至少有一个元素不属于 $A$，就说 $A$ 是 $B$ 的**真子集**，记作 $A \subsetneqq B$。

**例 3**：设 $A = \{1, 2\}$，$B = \{1, 2, 3\}$，则 $A \subsetneqq B$。

### 集合相等

如果 $A \subseteq B$ 且 $B \subseteq A$，则称集合 $A$ 与 $B$ **相等**，记作 $A = B$。

**例 4**：方程 $x^2 = 1$ 的解集是 $\{1, -1\}$，它等于 $\{x \mid x^2 = 1\}$。

!!! note
    空集是任何集合的子集，即 $\varnothing \subseteq A$ 对任意集合 $A$ 成立；空集是任何非空集合的真子集。

## 集合的基本运算

设 $A$、$B$ 是两个集合，全集记为 $U$。

- **交集**：$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$，即同时属于 $A$ 和 $B$ 的元素组成的集合。
- **并集**：$A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$，即属于 $A$ 或属于 $B$ 的元素组成的集合。
- **补集**：$A$ 相对于全集 $U$ 的补集是 $\complement_U A = \{x \mid x \in U \text{ 且 } x \notin A\}$，即全集中不属于 $A$ 的元素组成的集合。

**例 5**：设 $U = \{1, 2, 3, 4, 5\}$，$A = \{1, 2\}$，$B = \{2, 3\}$，则

$$A \cap B = \{2\}, \qquad A \cup B = \{1, 2, 3\}, \qquad \complement_U A = \{3, 4, 5\}.$$

上述三种运算可以用 **Venn 图**（用封闭曲线表示集合的图形）直观理解：交集是两圆重叠的公共部分，并集是两圆覆盖的全部区域，补集是圆外的区域。

## 集合的运算律

设 $A$、$B$、$C$ 是全集 $U$ 的子集，则下列运算律成立：

- **交换律**：$A \cup B = B \cup A$，$A \cap B = B \cap A$；
- **结合律**：$(A \cup B) \cup C = A \cup (B \cup C)$，$(A \cap B) \cap C = A \cap (B \cap C)$；
- **分配律**：$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$，$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$；
- **德摩根律（De Morgan 律）**：$\complement_U (A \cup B) = \complement_U A \cap \complement_U B$，$\complement_U (A \cap B) = \complement_U A \cup \complement_U B$。

**例 6**：德摩根律可以这样理解：$U = \{1, 2, 3, 4\}$，$A = \{1, 2\}$，$B = \{2, 3\}$，则 $\complement_U (A \cup B) = \complement_U \{1, 2, 3\} = \{4\}$，而 $\complement_U A \cap \complement_U B = \{3, 4\} \cap \{1, 4\} = \{4\}$，两边相等。

## 元素个数公式

若 $A$、$B$ 都是有限集，则

$$|A \cup B| = |A| + |B| - |A \cap B|,$$

其中 $|X|$ 表示集合 $X$ 中元素的个数。之所以要减去 $|A \cap B|$，是因为交集部分在 $|A| + |B|$ 中被重复计算了一次。

**例 7**：某班 40 人中，喜欢数学的有 25 人，喜欢物理的有 18 人，两科都喜欢的 10 人。则至少喜欢一科的人数为

$$|A \cup B| = 25 + 18 - 10 = 33,$$

两科都不喜欢的有 $40 - 33 = 7$ 人。

!!! note
    当 $A \cap B = \varnothing$ 时，公式简化为 $|A \cup B| = |A| + |B|$，此时称 $A$ 与 $B$ 不相交。
