# 符号表

> 本站数学符号的统一约定。正文中出现的符号应当以本表为准；
> 本表只列出可以被 MathJax 渲染的符号。

- `xxx(a)` 表示另一种写法；`xxx(r)` 表示符号左右翻转。

## 常用符号

完整符号表见 [symbols.md](symbols.md)，涵盖：

- **常用集合**：$\mathbb{N}$、$\mathbb{Z}$、$\mathbb{Q}$、$\mathbb{R}$、$\mathbb{C}$
- **集合运算**：$\cap$、$\cup$、$\subseteq$、$\in$、$\mathcal{P}(A)$
- **逻辑符号**：$\forall$、$\exists$、$\land$、$\lor$、$\rightarrow$、$\Leftrightarrow$
- **群论**：$H \leq G$、$H \unlhd G$、$H \cong G$
- **希腊字母**：$\alpha, \beta, \gamma, \ldots, \omega$

## 本站排版约定

| 记号             | 含义                                   |
| ---------------- | -------------------------------------- |
| `$...$`          | 行内公式（两侧不空格）                 |
| `$$...$$`        | 行间公式（独占一段）                   |
| **定义 1（名称）** | 定义标签 + 编号 + 名称                |
| `!!! note "..."` | 要点提示框                             |

如需扩展符号表，请在[贡献指南](../intro/contribute.md)的流程下提交。
