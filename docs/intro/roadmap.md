# 内容路线图

本站按"**从地基到高塔**"的顺序组织内容。下面列出各学科的目标内容与当前状态，
用 ✅ 表示已完成、🔄 表示编写中、⬜ 表示规划中。

完整的课程覆盖审计、缺口依据和优先级见[本科与研究生数学内容对照](curriculum-gap-analysis.md)。

## 后续计划

1. **P0 本科衔接**：高等线性代数、模与域扩张、点集/代数拓扑、ODE/PDE、测度概率、数值线性代数。
2. **P1 研究生基础**：交换代数、表示论与 Lie 理论、微分拓扑、调和分析、代数/解析数论、随机分析与遍历论。
3. **P2 专业方向**：代数几何、同调代数、几何分析、算子代数、控制/博弈/信息论和反问题。
4. 每个章节补充习题、证明细节与交叉链接，形成真正的知识网络。
