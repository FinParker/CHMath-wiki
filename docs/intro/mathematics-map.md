# 数学领域地图

> 数学不是彼此隔离的科目集合，而是一张由对象、结构、变化、空间、随机性与计算连接起来的网络。

## 主要领域之间的桥梁

- **代数几何**（algebraic geometry）：用交换代数研究多项式方程的几何解集。
- **代数拓扑**（algebraic topology）：用群和同调研究连续空间。
- **微分几何**（differential geometry）：用分析研究流形、曲率和测地线。
- **解析数论**（analytic number theory）：用复分析、Fourier 分析和概率思想研究整数。
- **几何分析**（geometric analysis）：用 PDE 研究曲率与整体几何，Ricci flow 是典型工具。
- **表示论**（representation theory）：把抽象对称群表示为线性变换，连接代数、几何、数论和物理。
- **随机分析**（stochastic analysis）：把测度论、随机过程与微分方程结合起来。
- **信息论**（information theory）：用熵和概率研究压缩、通信与推断的极限。
- **运筹学**（operations research）：结合优化、概率和算法进行决策与资源配置。
- **数学物理**（mathematical physics）：为力学、相对论、量子理论和统计物理建立严格结构。

## 推荐学习路径

### 从中学到大学基础

[初等数学](../elementary/index.md) → [微积分](../analysis/calculus/index.md) + [线性代数](../algebra/linear/index.md) → [实分析](../analysis/real/index.md) + [抽象代数](../algebra/structures/index.md) + [拓扑](../topology/index.md)。

### 概率与数据

微积分 → 线性代数 → [概率论](../probability_statistics/basics.md) → [多维分布](../probability_statistics/joint_distributions.md) → [数理统计](../probability_statistics/mathematical_statistics.md) / [随机过程](../probability_statistics/stochastic_processes.md)。

### 现代纯数学

逻辑与集合 → 抽象代数 + 实分析 + 点集拓扑 → Galois 理论 / 泛函分析 / 微分几何 / 代数拓扑 → 代数几何、表示论、几何分析等专题。

### 应用与计算

微积分 + 线性代数 + 编程 → 微分方程 → 数值分析 + 最优化 → 科学计算、控制、机器学习或运筹学。
