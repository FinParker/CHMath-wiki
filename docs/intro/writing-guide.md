# 写作规范

本页是 CHMath-wiki 的内容模板与写作规范。所有页面应遵循统一的结构与排版，
以保证大型 wiki 的一致性。

## 页面结构

每个内容页面推荐如下结构（可依主题调整）：

```markdown
---
title: 页面标题
tags:
  - 学科标签
---

# 页面标题

> 一句话定位：这个页面讲什么、为什么重要。（可选）

## 概述

正文开头：用自然语言讲清概念的本质与动机。

## 定义

**定义 1（名称）** 定义内容……

## 定理

**定理 1（名称）** 陈述……

**证明** 证明思路 + 严格证明……

## 例子

- 例子 1：……
- 例子 2：……

## 延伸阅读

- [相关页面1](relative/path.md)
- [相关页面2](relative/path.md)
```

## 数学公式规范

- 行内公式使用 `$...$`，**两侧不空格**：`$f(x) = x^2$`。
- 行间公式使用 `$$...$$`，独占一段：
  ```
  $$
  \lim_{x \to 0} \frac{\sin x}{x} = 1
  $$
  ```
- 公式一律使用 LaTeX 语法（MathJax 3 渲染）。常用环境：
  `\begin{cases}`、`\begin{aligned}`、`\begin{pmatrix}`、`\begin{array}`。
- 符号使用以[符号表](../notation/index.md)为准。

## 排版约定

- 标题使用 `#`（页面唯一 H1）与 `##`/`###`；不要跳级。
- 定义、定理、引理、推论统一用**加粗标签 + 编号**：`**定义 1（名称）**`。
- 需要强调的结论可用提示框：

  ```markdown
  !!! note "要点"
      关键结论写在提示框里。

  !!! warning "易错点"
      常见误区。
  ```

- 列表、表格、代码块按常规 Markdown 书写；代码块支持行号与高亮。
- 中英文之间建议留一个空格（如 "使用 MathJax 渲染"），公式前后自然衔接。

## Front matter

每个页面必须有 `title`；`tags` 建议 1–3 个，来自既有标签集合
（集合论、范畴论、代数、线性代数、分析、微积分、实分析、复分析、几何、
拓扑、数论、离散数学、组合数学、图论、自动机、概率与统计、技巧、初等数学、数理逻辑）。

## 交叉链接

- 链接使用相对路径：`[范畴](../foundations/category_theory/categories.md)`。
- 不要链接到尚不存在的页面（会破坏严格构建）；先创建页面再链接。
- 每个页面的"延伸阅读"至少包含 2 个相关链接，让知识形成网络。
