# 选择公理

选择公理（Axiom of Choice，AC）是数学中最著名、最受争议的公理：它直觉上显然（非空的抽屉总能各取一物），后果却惊人（良序定理、Zorn 引理、不可测集、Banach–Tarski）。本页讲清它的内容、等价形式、典型应用与逻辑地位。

## 陈述与直觉

**定义 1（选择函数）** 设$\mathcal{F}$是由非空集合组成的族。函数$f: \mathcal{F} \to \bigcup \mathcal{F}$称为选择函数，若$f(A) \in A$对每个$A \in \mathcal{F}$成立。

**公理（选择公理, AC）** 每个由非空集合组成的族$\mathcal{F}$都有选择函数。

**直觉**：有无穷多个"抽屉"（集合），每个抽屉非空。AC 断言可以**同时**从每个抽屉里拿一个东西——即使没有任何规则告诉你该怎么拿。

**等价说法**：

- 一族非空集合的笛卡尔积非空$\iff$每个因子非空（"乘积非空"版本）；
- 每个满射都有右逆（见 [函数](functions.md) 定理 4）。

!!! note "要点：AC 为什么不是显然的"
    对有限族，选择函数可逐抽屉归纳构造，无需公理。对无穷族，"同时选择"没有可循的有限步骤；选择函数的存在是一个**非构造性**的存在断言——它保证存在，但不给出选择的内容。直觉上的"显然"来自有限经验，推广到无穷需要论证。

**例 1（无需 AC 的情形）** 从$\mathbb{N}$的非空子集族中取最小元——$\mathbb{N}$良序，最小元唯一且显式，不需要 AC。从$\mathbb{R}$的非空子集族中取"最小元"则不行：$\mathbb{R}$的通常序下开区间无最小元。

## 弱化版本

- **可数选择公理（$\mathrm{AC}_\omega$）**：只对可数族成立。分析学常用（如"序列紧致蕴含紧致"的证明）。
- **依赖选择（DC）**：更强一些的弱化；Baire 范畴定理、实数完备性的一些论证用到。
- 这些弱化都不蕴含完整 AC；$\mathrm{AC}_\omega$也不蕴含 DC。

## 可数选择与数学分析

许多分析定理只需可数选择（$\mathrm{AC}_\omega$）：如"$f: \mathbb{R} \to \mathbb{R}$在一点连续当且仅当序列连续"的反证方向、Baire 范畴定理的某些版本。完整 AC 在这些场景中是"杀鸡用牛刀"；依赖选择（DC）覆盖更广，而 Solovay 模型保留了 DC。

**例 4（序列连续蕴含连续需要可数选择）** 设$f$在$a$处序列连续但不$\epsilon$-$\delta$连续。反证需要为每个$n$选一个$x_n$满足$|x_n - a| < 1/n$且$|f(x_n) - f(a)| \ge \epsilon$——这正是可数多次选择。事实上在 ZF 中"序列连续蕴含$\epsilon$-$\delta$连续"本身不可证：存在 ZF 模型使该命题失败。

## 常见疑问

**问：AC 与"每个集合非空"矛盾吗？** 不矛盾。单个集合非空只保证"存在某个元素"；AC 断言的是对一族非空集合**同时**完成选取，而且这种选取可以是"没有规则"的。

**问：可数选择够用吗？** 对许多分析结论够用（见上节）；但代数中 Zorn 引理式的论证、以及涉及不可数族（如$\mathbb{R}/\mathbb{Q}$的陪集族取代表）的情形，绕不开完整 AC。

**问：接受 AC 会"错"吗？** 不会。AC 与 ZF 相容（Gödel 的$L$），拒绝 AC 也与 ZF 相容（Cohen）。数学上二者都"一致"；选择取决于工作框架与哲学立场，而非正确性。

## 等价形式

**定理 1（在 ZF 中等价于 AC）**

1. **Zorn 引理**：每个非空偏序集，若每条链都有上界，则含极大元；
2. **良序定理**（Zermelo, 1904）：每个集合可以被良序化；
3. **Tychonoff 定理**（Kelley, 1950）：任意多个紧致拓扑空间的乘积（乘积拓扑）紧致；
4. **每个向量空间有基**（Blass, 1984）：任意域上的任意向量空间存在一组基；
5. **每个满射有右逆**；**一族非空集合的乘积非空**……

**证明方向（思路）**：

- **AC ⟹ 良序定理**：设$A$任意。用 AC 从$\mathcal{P}(A) \setminus \{\varnothing\}$取选择函数，超限递归地"逐个挑出$A$的元素"，直到挑完，得到的序就是良序；
- **良序定理 ⟹ AC**：沿$\mathcal{F}$的并的良序取"最小元素"，即得选择函数；
- **Zorn ⟹ AC**：考虑所有"部分选择函数"（定义在$\mathcal{F}$的某子族上的选择函数）按包含关系组成的偏序集。链的并仍是部分选择函数，是上界；Zorn 给出极大元$f$。若$f$的定义域不是整个$\mathcal{F}$，取定义域外的$A$（非空），挑一个$a \in A$扩张$f$，矛盾于极大性。故$f$是全选择函数；
- **AC ⟹ Zorn**：假定无极大元，用选择函数沿超限递归构造严格递增的链，与"链有上界"配合继续延伸，最终矛盾。$\blacksquare$

!!! note "要点：等价形式的意义"
    AC 的等价形式横跨代数（Zorn 引理）、序理论（良序定理）、拓扑（Tychonoff）、线性代数（基的存在）。接受其中任何一个就等于接受全部；反之，在任何一域构造反例（如无基的向量空间）都会波及其余领域。

!!! warning "易错点：Zorn 引理不是'显然的废话'"
    难点总在验证"**每条**链都有上界"这一前提——如向量空间基的证明中要验证"线性无关子集的并仍线性无关"。前提验证正确，极大元才自动出现。

## 典型应用

**定理 2（每个向量空间有基）** 设$V$是域$k$上的向量空间，则$V$有基（线性无关的生成集）。

**证明（用 Zorn 引理）** 令$\mathcal{S}$为$V$的所有线性无关子集按$\subseteq$组成的偏序集（非空：$\varnothing$线性无关）。设$\mathcal{C} \subseteq \mathcal{S}$是一条链，$U = \bigcup \mathcal{C}$。若$\sum a_i u_i = 0$（$u_i \in U$，$a_i$不全为零），每个$u_i$属于某个$C_i \in \mathcal{C}$；链中有限个成员有最大者，故所有$u_i$同属于某个$C \in \mathcal{C}$，而$C$线性无关，矛盾。故$U$线性无关，是$\mathcal{C}$的上界。Zorn 引理给出极大线性无关集$B$。若$v \notin \operatorname{span} B$，则$B \cup \{v\}$线性无关，矛盾于极大性；故$B$生成$V$。$\blacksquare$

**例 2（Vitali 集, 1905）** 在$\mathbb{R} / \mathbb{Q}$（实数模有理数的陪集族，见 [关系](relations.md) 的商集概念）的每个陪集中选一个代表，得到$V \subseteq [0, 1]$。$V$不是 Lebesgue 可测的：否则由平移不变性，$[0, 1]$会被可数个$V$的平移覆盖且这些平移互不相交地落在有界区间内，其测度和既是$0$又是正数，矛盾。要点：**不可测集的存在依赖 AC**——在 Solovay 的 ZF + DC 模型中，所有实数集都可测。

**例 3（Hamel 基）** 把$\mathbb{R}$看作$\mathbb{Q}$-向量空间，其基称为 Hamel 基。由定理 2 它存在，但不存在任何显式构造——AC 保证"存在"，却不给出"哪一个"。Hamel 基还给出$\mathbb{R}$作为$\mathbb{Q}$-向量空间的维数$2^{\aleph_0}$：一个不可数的维数，其存在本身只能由 AC 保证。

!!! note "要点：AC 的'标配'地位"
    主流数学事实上默认 ZFC：Hahn–Banach 定理、代数闭包的存在性、一阶逻辑紧致性定理等通常都被当作"可用工具"。其中 Hahn–Banach 在 ZF 中**严格弱于 AC**（可由超滤子引理/布尔素理想定理推出），是"几乎用不到完整 AC"的典型。

## 独立性：Cohen 的力迫法

**定理 3（AC 独立于 ZF）**

- **Gödel（1938, 详文 1940）**：若 ZF 一致，则 ZFC 一致——在可构造宇宙$L$中，AC 与 GCH 都成立；
- **Cohen（1963）**：若 ZF 一致，则 ZF + ¬AC 一致——Cohen 用**力迫法**（forcing）构造出 ZF 模型，其中存在没有选择函数的非空集合族（如由可数多个"无序对"组成的族）。

因此 AC 在 ZF 中**独立**：既不能证明，也不能否证。Cohen 的力迫法同时证明了 ¬CH 与 ZFC 相容（见 [基数与势](cardinality.md)），是 20 世纪数学基础的最大突破之一；Cohen 于 1966 年因此获 Fields 奖章。

!!! note "要点：独立性的含义"
    "AC 独立于 ZF"不是说 AC 是错的，而是说 ZF 的公理不足以裁决它。接受或拒绝 AC 得到不同的集合论宇宙：$L$中 AC 成立，Cohen 模型中不成立。选择是数学家的自由，但后果必须承担。

**力迫法的思想（简述）**：从一个 ZF 模型$M$出发，向其中"强迫加入"新的对象（如新的实数子集），得到扩张模型$M[G]$；$M[G]$仍满足 ZF 的公理，但某些命题的真值被改变。Gödel 的可构造宇宙$L$是最小的 ZFC 模型（AC 与 GCH 在其中成立），Cohen 的力迫扩张则制造出 AC 或 CH 失败的新宇宙——两座模型合起来，就完成了独立性证明。

## 数学家的态度

- **主流（ZFC）**：绝大多数数学家默认 AC。理由：几乎处处好用（Zorn 引理是代数的万能工具）、等价形式自然、拒绝的代价（无基的向量空间、非紧的乘积）看上去更"病态"。
- **构造性数学**（Bishop 等）：拒绝非构造性的存在断言。有趣的是，构造性（直觉主义）逻辑中某些选择反而是逻辑可证的，而 ZFC 式的完整 AC 不被采用。
- **集合论学家**：研究 AC 的各种强弱形式与模型；普遍接受 ZFC，但清楚它的边界与替代品。
- **Banach–Tarski 悖论（1924）**：用 AC 可把单位球分成有限块，经平移与旋转拼成两个单位球。这常被引为"AC 的荒谬后果"，但它只是说明"体积"概念无法扩展到任意集合（分块不可测）；在 ZF 中 Banach–Tarski 与 AC 互相独立（由它可推出不可测集的存在，故 ZF 中不可证；且它不蕴含 AC，Foreman–Wehrung, 1991）。

!!! warning "易错点：Banach–Tarski 不是矛盾"
    Banach–Tarski 分解的是数学上的"点集"，分解出的块**不可测**，"体积"对它们无定义。它揭示的是：选择公理允许"足够病态"的集合存在，而不是说体积守恒被打破。

## 历史：Zermelo 1904 与争论的开端

Zermelo 1904 年用 AC 证明了良序定理（见 [序数](ordinals.md)），随即引发激烈争论：许多数学家觉得"每个集合都能良序化"太强（它的后果包括不可测集），而 Zermelo 坚持选择是"逻辑原理"。争论的产物是：Zermelo 1908 年把 AC 明确列为公理，并给出他的公理化集合论（ZF 的前身，见 [zfc.md](zfc.md)）。这场争论的另一个遗产是"集合论的数学化"：AC 的争议迫使数学家重新审视"什么是可接受的存在证明"，并催生了构造性数学、可定义性理论等方向。今天，AC 的地位更像"默认设置"而非"教条"。

## AC 在数学各领域中的角色

- **代数**：Zorn 引理（AC 的等价形式）证明每个环有极大理想、每个域有代数闭包（Steinitz, 1910）、每个向量空间有基；
- **分析**：Hahn–Banach 定理（弱于 AC）、Baire 范畴定理的某些版本、Vitali 不可测集；
- **拓扑**：Tychonoff 定理（等价于 AC）、非主超滤子的存在（可由超滤子引理/布尔素理想定理得到，弱于 AC）；
- **序与组合**：Hausdorff 极大原理（与 Zorn 引理等价）、实数作为$\mathbb{Q}$-向量空间的 Hamel 基。

!!! note "要点：多数'应用'实际用的是等价形式"
    大多数应用并不直接"逐个选择元素"，而是用 Zorn 引理或良序定理。学会在具体问题中验证"每条链有上界"（如向量空间基的证明）比记住 AC 的陈述本身更重要。

## 没有 AC 的世界

- **Solovay 模型（1970）**：ZF + 依赖选择（DC）的模型，其中所有实数集 Lebesgue 可测——Vitali 集不存在，Banach–Tarski 不可能；
- **无基的向量空间**：由 Blass 定理（"每个向量空间有基" ⟺ AC），在 ¬AC 的模型中必然存在没有基的向量空间；
- **Cohen 第一模型**：存在由可数多个无序对组成的集合族，没有选择函数；
- **Fraenkel–Mostowski 模型（1922/1938）**：用带原子（urelement）的集合论早已给出 ¬AC 的相容性，但原子破坏了"一切皆集合"；Cohen 的方法去掉原子，在纯 ZF 中实现同样的结论；
- **描述集合论**：Borel 集、解析集理论在 ZF + DC 下发展良好，许多结果不依赖完整 AC——"DC 是分析的安全区间"是常见的经验法则。

!!! note "要点：DC 与$\mathrm{AC}_\omega$的强度"
    DC 蕴含$\mathrm{AC}_\omega$，$\mathrm{AC}_\omega$蕴含有限选择；三者都严格弱于完整 AC。DC 恰是"沿良基关系逐层选择"所需的强度，Baire 范畴定理、Cauchy 序列极限的存在性等常以 DC 为界。

这些模型表明：AC 不是"数学的事实"，而是"集合论宇宙的一种选择"。同一个命题（如"所有实数集都可测"）在一个宇宙中为真、在另一个宇宙中为假——数学不是"唯一的宇宙"，而是"框架的家族"；公理的取舍是框架的一部分。

## 一句话总结

选择公理断言：**无穷多个非空集合可以同时各取一个元素**。它直觉上显然、应用中无价、逻辑上独立——接受它，得到 ZFC 的整齐宇宙；拒绝它，得到更复杂但更"构造"的集合论。

## 小结：什么时候需要 AC

- **必须 AC（或与 AC 等价）**：Zorn 引理式论证、每个向量空间有基、Tychonoff 定理、良序定理；
- **弱化版本即可**：序列连续蕴含连续（$\mathrm{AC}_\omega$）、Baire 范畴定理（DC）、Hahn–Banach 定理（布尔素理想定理）；
- **不需要 AC**：取最小元或唯一元素的选取、有限族选择、CBS 定理（构造是显式的，见 [基数与势](cardinality.md)）。

一句话：能显式就不需要，无穷任意选才要 AC，能用弱形式就别用完整 AC。
