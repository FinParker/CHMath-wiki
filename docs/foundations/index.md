# 数学基础

> 现代数学的语言与地基：数理逻辑告诉我们"如何推理"，集合论提供"讨论的对象"，
> 范畴论给出“结构之间的映射”，类型论则把证明、计算与数学对象组织在同一语言中。

## 学习顺序建议

1. 先掌握[命题逻辑](logic/propositional_logic.md)与[谓词逻辑](logic/predicate_logic.md)。
2. 进入[集合论](set_theory/index.md)：基本概念 → 关系与函数 → 基数与序数。
3. 在熟悉集合与函数之后，进入[范畴论](category_theory/index.md)。
4. 通过[证明论](logic/proof_theory.md)理解证明的结构，再学习[类型论](type_theory/index.md)。
5. 最后沿 Lambda Cube → HoTT → CuTT 的路线理解依赖与高维等同。
