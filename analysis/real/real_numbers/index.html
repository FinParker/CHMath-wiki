    实数公理¶

    实数系 \(\mathbb{R}\) 是整个数学分析的基石。微积分中的极限、连续、导数与积分,归根结底

    都是关于"实数之间距离的逼近过程"的精确描述。因此,回答"实数到底是什么"是分析学

    的第一课。

    为什么有理数 \(\mathbb{Q}\) 不够用?直观理由是"有漏洞":方程 \(x^2 = 2\) 没有有理数解。

    若 \(x = p/q\)(\(p, q\) 互素)满足 \(p^2 = 2q^2\),则 \(2 \mid p^2\),于是 \(2 \mid p\),

    设 \(p = 2k\),代入得 \(2k^2 = q^2\),又 \(2 \mid q\),与互素矛盾。但数轴上 \(\sqrt{2}\)

    的位置"应该"存在——用有理数无法表示它,却可以用有理数任意逼近它。实数就是把这类

    "逼近的极限"补充进来的结果。

    本页从公理化的角度刻画实数:实数系是一个满足三组公理的数学结构——域公理(代数结构)、

    序公理(大小关系)与完备性公理(没有"空隙")。其中完备性公理是实数区别于有理数的

    关键,也是分析学中一切存在性定理的源泉。

    为什么需要公理化

    直观上,实数就是"数轴上的点"。但数学要求精确:我们不说实数"是什么",而说实数

    "满足什么公理"。任何满足这三组公理的结构都同构于 \(\mathbb{R}\),即实数系在同构

    意义下唯一。

    域公理¶

    定义 1（域） 一个集合 \(F\) 连同两个运算 \(+ : F \times F \to F\)、\(\cdot : F \times F \to F\)

    称为域,如果满足以下公理:

    加法公理:

    1. 结合律:\((a+b)+c = a+(b+c)\);
    2. 交换律:\(a+b = b+a\);
    3. 零元:存在 \(0\) 使得 \(a+0 = a\);
    4. 负元:对每个 \(a\) 存在 \(-a\) 使得 \(a+(-a) = 0\)。

    乘法公理:

    1. 结合律:\((ab)c = a(bc)\);
    2. 交换律:\(ab = ba\);
    3. 幺元:存在 \(1 \neq 0\) 使得 \(a \cdot 1 = a\);
    4. 逆元:对每个 \(a \neq 0\) 存在 \(a^{-1}\) 使得 \(aa^{-1} = 1\)。

    分配律:

    1. \(a(b+c) = ab + ac\)。

    例 1 \(\mathbb{Q}\) 与 \(\mathbb{R}\) 都是域;整数集 \(\mathbb{Z}\) 不是域(除 \(1\) 与 \(-1\) 外没有

    乘法逆元)。

    序公理¶

    定义 2（全序） 集合 \(F\) 上的二元关系 \(\le\) 称为全序,若满足:

    • 自反性:\(a \le a\);
    • 反对称性:\(a \le b\) 且 \(b \le a \implies a = b\);
    • 传递性:\(a \le b\) 且 \(b \le c \implies a \le c\);
    • 完全性:任意 \(a, b\) 都有 \(a \le b\) 或 \(b \le a\)。

    定义 3（有序域） 域 \(F\) 上的全序 \(\le\) 若还满足

    • 加法相容:\(a \le b \implies a + c \le b + c\);
    • 乘法相容:\(0 \le a,\, 0 \le b \implies 0 \le ab\),

    则称 \((F, +, \cdot, \le)\) 为有序域。

    由序公理可以推出绝对值、三角不等式、\(0 < a \implies 0 < a^{-1}\) 等日常性质。\(\mathbb{Q}\)

    与 \(\mathbb{R}\) 都是有序域;复数域 \(\mathbb{C}\) 不是有序域(见 复数

    一页的相关讨论)——这也是"序"与"完备性"必须放在实数框架内谈的原因。

    完备性公理¶

    定义 4（上界与上确界） 设 \(E \subseteq \mathbb{R}\) 非空。

    • \(b\) 称为 \(E\) 的上界,若对一切 \(x \in E\) 有 \(x \le b\);
    • \(s\) 称为 \(E\) 的上确界(最小上界),记 \(s = \sup E\),若 \(s\) 是 \(E\) 的上界,且 \(E\) 的

    任何上界 \(b\) 都满足 \(s \le b\)。

    公理 1（完备性公理,确界原理） \(\mathbb{R}\) 中每个非空有上界的子集都有上确界。

    定义 5（完备有序域） 同时满足域公理、序公理与完备性公理的数学结构称为完备有序域。

    例 2 \(\sup(0, 1) = 1\)、\(\inf(0, 1) = 0\)(端点不必属于集合);\(\sup\{1 - 1/n : n \in \mathbb{N}\} = 1\);

    \(\sup \mathbb{Z} = +\infty\)(无上界,非实数)。注意上确界与最大值的区别:最大值必须属于集合,

    上确界不必。

    有界性的要求不能省

    非空集合 \(E\) 若没有上界,则记 \(\sup E = +\infty\)(它不是一个实数);空集没有上确界。

    确界原理只对非空有上界集合作出断言。同理可定义下确界 \(\inf E\)。

    定理 1（下确界原理） 非空有下界的集合必有下确界。

    证明思路:设 \(E\) 有下界,则 \(-E = \{-x : x \in E\}\) 有上界,由确界原理 \(\sup(-E)\) 存在,

    且 \(\inf E = -\sup(-E)\)。这一"负号翻折"技巧在分析中反复出现。

    阿基米德性质¶

    定理 2（阿基米德性质） 对任意 \(a > 0\) 与 \(b \in \mathbb{R}\),存在 \(n \in \mathbb{N}\) 使得 \(na > b\)。

    证明思路:反证。若对所有 \(n\) 都有 \(na \le b\),则集合 \(A = \{na : n \in \mathbb{N}\}\) 非空且有

    上界 \(b\)。由确界原理设 \(s = \sup A\)。于是 \(s - a\) 不是 \(A\) 的上界,存在 \(n\) 使 \(na > s - a\),

    即 \((n+1)a > s\),与 \(s\) 是上界矛盾。

    阿基米德性质的通俗表述:无论 \(a\) 多小、\(b\) 多大,\(a\) 的整数倍总能超过 \(b\);等价地说,

    \(\mathbb{R}\) 中不存在"无穷小正实数"。

    推论 1 对任意 \(\varepsilon > 0\),存在 \(n \in \mathbb{N}\) 使 \(1/n < \varepsilon\)。由此立得 \(1/n \to 0\)

    (\(n \to \infty\)),这是极限论最基本的例子:对任意 \(\varepsilon > 0\) 取 \(N > 1/\varepsilon\) 即可。

    有理数在实数中稠密¶

    定理 3（稠密性） 对任意 \(x < y\),存在有理数 \(r\) 满足 \(x < r < y\)。

    证明思路:由阿基米德性质取 \(n\) 使 \(n(y-x) > 1\),即 \(1/n < y - x\)。令 \(m = \lceil nx \rceil\)

    (不小于 \(nx\) 的最小整数),则 \(m - 1 < nx \le m\),于是

    \[x < \frac{m}{n} \le x + \frac{1}{n} < y,\]

    取 \(r = m/n\) 即得。证明的关键是把"找有理数"转化为"找整数 \(m\)"——整数的离散性配合

    \(1/n\) 的可任意小性。

    稠密性与完备性的关系

    稠密性说的是:任何两个实数之间都有有理数(同理也有无理数)。完备性说的是更强的命题:

    任何"应存在的点"都存在(例如 \(\sqrt{2}\)、\(\pi\) 所在的位置)。\(\mathbb{Q}\) 也稠密,

    但不完备——这正是分析学必须引入 \(\mathbb{R}\) 的原因。

    实数的构造¶

    公理化路线用公理规定 \(\mathbb{R}\) 应满足的性质,但从逻辑上讲还需确认:确实存在满足这三组

    公理的对象。两种经典构造:

    Dedekind 分割。 把每个实数等同于有理数集的一个分割 \((A \mid B)\):其中 \(A\) 是非空、

    不含最大元、且对小于运算封闭的有理数真子集。例如 \(\sqrt{2}\) 对应分割

    \(A = \{r \in \mathbb{Q} : r^2 < 2 \text{ 或 } r < 0\}\)。在分割集合上定义加法、乘法与序,

    可验证得到完备有序域。这种构造几何直观(分割的"缺口"即实数),但乘法的定义比较繁琐。

    Cauchy 序列。 把每个实数等同于有理 Cauchy 序列的等价类(两个序列等价若其差趋于 \(0\)),

    并在等价类上逐点定义运算。这种构造更贴近"实数由有理数的逼近过程产生"的直观,也便于

    推广为度量空间的完备化。

    两种构造殊途同归:得到的完备有序域在同构意义下唯一。这也印证了公理化的力量:我们关心的

    不是实数的"具体模样",而是它满足的公理。

    完备性的等价刻画¶

    确界原理只是完备性的一种表述。事实上,分析学中一系列"存在性定理"彼此等价:

    定理 4（完备性等价定理） 以下命题等价:

    1. 确界原理:非空有上界的集合有上确界;
    2. 单调有界定理:单调有界序列收敛;
    3. 闭区间套定理:若 \([a_{n+1}, b_{n+1}] \subseteq [a_n, b_n]\) 且 \(b_n - a_n \to 0\),则存在

    唯一的 \(x\) 属于所有区间; 4. Bolzano–Weierstrass 定理:\(\mathbb{R}\) 中有界序列有收敛子列; 5. Cauchy 完备性:\(\mathbb{R}\) 中每个 Cauchy 序列收敛。

    证明按 \(1 \Rightarrow 2 \Rightarrow 3 \Rightarrow 4 \Rightarrow 5 \Rightarrow 1\) 的链条进行,

    我们给出每步的关键思想。

    \(1 \Rightarrow 2\):设 \((a_n)\) 单调递增且有上界。由确界原理,\(s = \sup\{a_n\}\) 存在。对任意

    \(\varepsilon > 0\),\(s - \varepsilon\) 不是上界,故存在 \(a_N > s - \varepsilon\);由单调性,

    \(n \ge N\) 时 \(s - \varepsilon < a_n \le s\),即 \(a_n \to s\)。这里"上确界就是极限"的思想

    贯穿整个分析:用确界定义极限,再用 \(\varepsilon\) 语言验证。

    \(2 \Rightarrow 3\):\((a_n)\) 单调递增有上界 \(b_1\),收敛于 \(a\);\((b_n)\) 单调递减有下界 \(a_1\),

    收敛于 \(b\)。由 \(b_n - a_n \to 0\) 得 \(a = b =: x\)。又 \(a_n \le x \le b_n\) 对所有 \(n\) 成立,

    故 \(x \in \bigcap_n [a_n, b_n]\);唯一性由区间长度趋于 \(0\) 保证。

    \(3 \Rightarrow 4\):设 \((x_n)\) 有界于 \([a, b]\)。将区间二等分,两半中至少一半含有 \((x_n)\) 的

    无穷多项,取这一半为 \([a_1, b_1]\);重复此过程得闭区间套 \([a_n, b_n]\),每个区间含无穷多项

    且长度 \((b-a)/2^{n-1} \to 0\)。由 \(3\) 存在 \(x \in \bigcap_n [a_n, b_n]\)。依次从每个区间中

    挑选一项 \(x_{n_k}\)(保证下标严格递增),则 \(|x_{n_k} - x| \le (b-a)/2^{k-1} \to 0\),即

    \((x_{n_k})\) 收敛于 \(x\)。

    \(4 \Rightarrow 5\):设 \((x_n)\) 为 Cauchy 序列。先证有界:取 \(N\) 使 \(n, m \ge N\) 时

    \(|x_n - x_m| < 1\),则 \((x_n)\) 被 \(\max\{|x_1|, \ldots, |x_{N-1}|, |x_N| + 1\}\) 控制。由 \(4\)

    有收敛子列 \(x_{n_k} \to x\)。给定 \(\varepsilon > 0\),取 \(K\) 使 \(|x_{n_k} - x| < \varepsilon/2\),

    取 \(N\) 使 \(n, m \ge N\) 时 \(|x_n - x_m| < \varepsilon/2\);当 \(n \ge \max(N, n_K)\) 时

    \[|x_n - x| \le |x_n - x_{n_K}| + |x_{n_K} - x| < \varepsilon,\]

    即 \(x_n \to x\)。这一 \(\varepsilon/2\) 技巧("子列极限 + Cauchy 性")是序列证明的典型套路。

    \(5 \Rightarrow 1\):设 \(E\) 非空有上界。取 \(a_1 \in E\)、\(b_1\) 为 \(E\) 的上界,二分构造:设

    \(m_n = (a_n + b_n)/2\),若 \(m_n\) 是 \(E\) 的上界,令 \(a_{n+1} = a_n\)、\(b_{n+1} = m_n\);否则

    \(m_n\) 不是上界,取 \(a_{n+1} \in E\) 使 \(a_{n+1} > m_n\)(这样的元素存在),令 \(b_{n+1} = b_n\)。

    两种情形都有 \(b_{n+1} - a_{n+1} \le (b_n - a_n)/2\),故 \(b_n - a_n \le (b_1 - a_1)/2^{n-1} \to 0\)。

    于是 \(a_n\) 与 \(a_{n+k}\) 同落在 \([a_n, b_n]\) 内,\(|a_{n+k} - a_n| \le b_n - a_n \to 0\),

    即 \((a_n)\) 是 Cauchy 序列(这是关键一步),由 \(5\) 收敛于 \(s\);再由 \(b_n - a_n \to 0\) 得

    \(b_n \to s\)。验证 \(s = \sup E\):\(s\) 是上界,否则存在 \(x \in E\) 使 \(x > s\),但每个 \(b_n \ge x\)

    且 \(b_n \to s\),矛盾;\(s\) 最小,因为对任意 \(\varepsilon > 0\),由 \(a_n \to s\) 存在

    \(a_n > s - \varepsilon\),而 \(a_n \in E\),故 \(s - \varepsilon\) 不是上界。

    为什么这些定理等价

    五条定理的共通本质是"不存在空隙":完备性保证任何由有理数逼近的目标在 \(\mathbb{R}\) 内

    "落地"。它们分别以集合(确界)、序列(单调)、区间(闭区间套)、子列(Bolzano–Weierstrass)、

    距离(Cauchy)五种语言说出同一件事。在一般度量空间里这些等价关系会破裂(例如函数空间

    \(C[0,1]\) 完备,但其中有界集未必有收敛子列),值得留意。
